# Frontend PRD

Build an accessible, responsive private-workspace SPA ready for common SaaS use cases. Must-have: sign-in and registration, dashboard, tasks, activity, settings, typed API contracts, loading/error states, permission-aware navigation, secure session handling, accessibility, performance and CI. The page layout and code are intentionally customizable, without hardwiring business domains beyond the sample task feature. For SSR-heavy public sites, select a separate web platform template.
