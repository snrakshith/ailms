# Neural classifier and architecture study

Train a PyTorch MLP or CNN and compare two controlled changes.

## Deliverables
- [ ] Dataset manifest
- [ ] explicit training/evaluation loops
- [ ] loss curves
- [ ] checkpoint
- [ ] ablation
- [ ] error analysis

## Acceptance criteria
Validation selects best run; checkpoint reload agrees; record hardware and seed.

## Grading rubric (100 points)
- Functional Correctness: 30
- Evaluation And Evidence: 30
- Reproducibility And Documentation: 20
- Safety And Reliability: 20

Suggested pass: 75/100, with no unresolved critical safety or data leakage issue. Submit repository, test output and evaluation report.
