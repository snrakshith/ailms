# Tabular prediction service

Predict a binary target using a public or synthetic dataset.

## Deliverables

- [ ] Data dictionary and leakage-safe split
- [ ] baseline and two candidates
- [ ] validation-based threshold
- [ ] holdout report
- [ ] packaged pipeline

## Acceptance criteria

No holdout tuning; reproducible metrics; minority error analysis; inference handles unseen categories.

## Grading rubric (100 points)

- Functional Correctness: 30
- Evaluation And Evidence: 30
- Reproducibility And Documentation: 20
- Safety And Reliability: 20

Suggested pass: 75/100, with no unresolved critical safety or data leakage issue. Submit repository, test output and evaluation report.
