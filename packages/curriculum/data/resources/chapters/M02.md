## M02-L01 — Linear and polynomial regression

### Core concept
Ordinary least squares minimizes squared residuals. Polynomial features add nonlinear basis functions while coefficients remain linear. Residual diagnostics reveal systematic errors; extrapolation can be unreliable.

### Theory and reasoning
Linear regression minimizes squared residuals; polynomial expansion permits nonlinear dependence while the estimator stays linear in coefficients. High degrees increase capacity and numerical instability. RMSE emphasizes large errors and is measured in target units.

### Worked scenario
Predict house prices and plot residuals against fitted values.

### Design and verification
Selecting degree 10 from training error encourages overfit; plot validation error and investigate extrapolation outside training range.

### Practice
Fit degrees 1, 3 and 10 and compare validation RMSE.

Acceptance: Select the model by validation performance, not lowest training error.

## M02-L02 — Logistic regression and classification thresholds

### Core concept
Logistic regression maps a linear score to a probability using the sigmoid for binary outcomes. Training often minimizes log loss; deployment chooses a decision threshold based on error costs.

### Theory and reasoning
Logistic regression maps a linear logit to sigmoid probability. Thresholding probabilities is a separate decision, controlled by cost and review capacity. Increasing threshold usually reduces false positives and recall, though precision need not be monotonic.

### Worked scenario
Change a fraud threshold from 0.5 to 0.2 and observe recall and false alarms.

### Design and verification
Using .5 regardless of imbalance/cost may exceed budget or miss positives. Calibrate scores and pick threshold on validation, not test.

### Practice
Plot precision and recall for several thresholds and pick one for a review capacity.

Acceptance: Decision threshold is justified by validation costs, not by test outcomes.

## M02-L03 — k-nearest neighbors, naive Bayes and SVM

### Core concept
kNN predicts using nearby samples; naive Bayes factorizes features conditionally on class; SVM optimizes a margin and may use kernels. Their inductive biases and scaling behavior differ.

### Theory and reasoning
kNN predicts using nearby points; scaling changes distances. Naive Bayes estimates class-conditional likelihood under simplifying independence assumptions. SVM maximizes a margin with kernels for nonlinear boundaries; large data can make kernel SVM expensive.

### Worked scenario
Compare all three on a standardized small classification dataset.

### Design and verification
Distance model dominated by an unscaled income feature; inspect scaled distributions and use same folds for fair comparison.

### Practice
Cross-validate three models using identical folds and report score and fit time.

Acceptance: Preprocessing is inside folds and trade-offs are documented.

## M02-L04 — Decision trees and random forests

### Core concept
A tree greedily partitions feature space using impurity or loss reduction. A random forest aggregates trees trained on resampled data and random feature subsets, reducing variance compared with many individual trees.

### Theory and reasoning
Trees recursively split to reduce impurity; unconstrained depth can memorize noise. Random forests aggregate decorrelated trees trained on bootstrap samples and random feature subsets, reducing variance. More trees reduce Monte Carlo variability but cost memory and inference.

### Worked scenario
Train a shallow tree and random forest on a nonlinear classification task.

### Design and verification
Training accuracy reaches 1.0 but validation declines; reduce depth, min_samples_leaf or use a forest and verify on unseen data.

### Practice
Compare train and validation scores across tree depths and forest sizes.

Acceptance: Report the generalization gap and a stable configuration.

## M02-L05 — Gradient boosting: XGBoost, LightGBM and CatBoost

### Core concept
Boosting builds an additive model by fitting successive learners to loss gradients or related targets. Learning rate, tree complexity and iterations trade bias, variance and computation. Libraries differ in categorical handling and histogram strategies.

### Theory and reasoning
Boosting sequentially fits learners to gradients of a loss, so each stage corrects ensemble errors. Learning rate, iteration count and tree depth interact. Histogram boosting bins features; external XGBoost, LightGBM and CatBoost differ in categorical support and implementation.

### Worked scenario
Train a histogram gradient boosting baseline before trying external libraries.

### Design and verification
Using test as early-stopping eval_set leaks labels. Use validation; preserve a final test and exact package version.

### Practice

Acceptance: Log validation metric, runtime and chosen iteration count.

## M02-L06 — Regularization, feature selection and bias-variance

### Core concept
L1 penalties can produce sparse coefficients; L2 shrinks coefficients. Feature selection reduces dimensionality but must be part of training folds. Bias is systematic approximation error; variance reflects sensitivity to the sample.

### Theory and reasoning
Expected squared error can be decomposed into noise, bias² and variance under standard assumptions. L2 shrinks coefficients; L1 can set coefficients to zero. Feature selection must be nested inside validation. Learning curves reveal whether more data or capacity may help.

### Worked scenario
Compare Ridge and Lasso across penalty strengths on correlated features.

### Design and verification
Feature selection performed using all labels leaks information; put SelectKBest inside pipeline and rerun cross-validation.

### Practice
Plot learning curves and validation error for several penalty strengths.

Acceptance: Identify high bias or high variance and propose one intervention.
