## D03-L01 — CNN foundations and receptive fields

### Core concept

Convolution slides kernels over spatial input with shared weights. Stride, padding and dilation control output dimensions and receptive field. Pooling summarizes neighborhoods and may reduce resolution.

### Theory and reasoning

Convolution output per dimension is floor((n+2p−d(k−1)−1)/s+1). Local receptive fields expand with depth and stride; shared weights reduce parameter count. Padding and pooling alter spatial resolution.

### Worked scenario

Apply a 3x3 edge kernel and calculate output dimensions for stride 2.

### Design and verification

Flatten size mismatch occurs when stride/padding changes. Print intermediate shapes or infer feature dimension with a dummy pass.

### Practice

Acceptance: Computed shapes match actual tensor shapes.

## D03-L02 — RNNs, LSTMs, GRUs and sequence modeling

### Core concept

RNNs update hidden state from current input and previous state. LSTM and GRU gates help control information flow and mitigate some long-range gradient issues. Padding and masks matter for variable-length sequences.

### Theory and reasoning

RNN updates state sequentially; LSTM and GRU use gates to control information retention and mitigate vanishing gradients. Sequence batching requires consistent dimensions and masking padded positions. Temporal split is essential.

### Worked scenario

Predict the next symbol in a toy sequence with a GRU.

### Design and verification

Using padded last timestep instead of true sequence end corrupts representation; gather last valid state or pack sequences.

### Practice

Acceptance: Evaluate on sequences not used in training and explain failure cases.

## D03-L03 — Attention and transformers

### Core concept

Scaled dot-product attention computes softmax(QK^T/sqrt(d))V. Multihead attention captures different projections. Transformers combine attention, feedforward layers, residuals, normalization and position information; causal masks prevent attending to future tokens.

### Theory and reasoning

Scaled dot-product attention computes softmax(QKᵀ/√d)V. Causal mask assigns −∞ to future positions before softmax. Attention's quadratic sequence-length cost is a major long-context bottleneck (implementation optimizations may reduce memory).

### Worked scenario

Compute attention weights for three tokens and compare masked versus unmasked output.

### Design and verification

Applying mask after softmax leaves incorrect normalization; mask scores before softmax, avoid fully masked rows or define safe handling.

### Practice

Implement small causal attention with a triangular mask and test future-token invariance.

Acceptance: Changing future tokens does not alter earlier outputs.

## D03-L04 — Encoder, decoder and encoder-decoder architectures

### Core concept

Encoders typically use bidirectional context for representations; decoder-only language models use causal attention for next-token generation; encoder-decoder models condition decoding on encoded input. Architecture choice affects masking and training objectives.

### Theory and reasoning

Encoder self-attention typically sees all source positions; decoder-only autoregressive models mask future tokens; encoder-decoder combines bidirectional source encoding, causal target self-attention and cross-attention to source. Training objectives differ.

### Worked scenario

Compare BERT-like classification, GPT-like generation and T5-like summarization.

### Design and verification

Allowing target positions to attend to future target tokens during training creates leakage; use causal target mask.
