## C04-L01 — Video, optical flow and object tracking

### Core concept
Optical flow estimates apparent motion; tracking links detections through time using motion and appearance. Kalman filters estimate state under uncertainty; assignment methods associate observations. Tracking metrics measure detection and identity continuity.

### Theory and reasoning
Optical flow estimates apparent pixel motion; tracking associates detections across frames using motion, appearance or both. Occlusion, camera motion and missed detections cause ID switches. Detection precision and tracking identity metrics are different.

### Worked scenario
Track moving shapes across frames with simple centroid matching.

### Design and verification
Nearest-neighbor association swaps IDs at crossings; add motion prediction/appearance and evaluate on crossing cases.

### Practice
Create a synthetic video sequence with crossing objects and compare identity errors.

## C04-L02 — Vision transformers, CLIP and multimodal vision

### Core concept
Vision Transformers tokenize image patches and use attention. CLIP-style models align image and text embeddings through contrastive learning; zero-shot classification compares image embeddings with textual class descriptions.

### Theory and reasoning
ViT splits images into patch tokens with positional information and transformer layers. CLIP-style contrastive learning aligns image/text embeddings; zero-shot classification depends on prompts and distribution. Similarity scores are not calibrated probabilities.

### Worked scenario
Compare class text prompts for a small image set and measure prompt sensitivity.

### Design and verification
Choosing prompts after seeing test labels overfits benchmark. Tune on development images and freeze templates.

### Practice
Evaluate two prompt templates and inspect misclassified images.

Acceptance: Report macro F1 and prompt sensitivity on a fixed split.

## C04-L03 — OCR, document AI, 3D and deployment

### Core concept
OCR often combines text detection and recognition; document AI adds layout and structure. Depth can come from stereo geometry or learned models. Deployment uses batching, quantization and export formats such as ONNX; preprocessing must match training.

### Theory and reasoning
OCR separates text detection, recognition and layout reading order; document QA often needs page/region provenance. 3D tasks add geometry/depth assumptions. ONNX export can change operator support or numeric behavior; compare runtime outputs before deployment.

### Worked scenario
Extract text from synthetic receipts and benchmark an exported classifier.

### Design and verification
Comparing normalized vs original-size boxes breaks source citations; retain page coordinates and transformation metadata.
