## C02-L01 — Image datasets, augmentation and labeling

### Core concept

Augmentations simulate plausible variation such as crop, flip or lighting change. Labels must be transformed consistently with images for detection and segmentation. Group splits prevent leakage across near-duplicate frames or patients.

### Theory and reasoning

Dataset audit checks label consistency, near-duplicates, class balance and capture-group leakage. Augmentations should preserve labels; geometric transforms must move boxes/masks consistently. Validation should represent actual inference preprocessing.

### Worked scenario

Build transforms for classification and bounding boxes; split by video source.

### Design and verification

Applying random augmentation to validation changes reported metric across runs; use deterministic transforms and preserve labels.

### Practice

Create a dataset audit with class counts, duplicates, split groups and annotation examples.

Acceptance: Validation transforms are deterministic and label geometry remains consistent.

## C02-L02 — Image classification and pretrained CNNs

### Core concept

ResNet uses residual connections to ease deep optimization; EfficientNet scales architecture dimensions systematically. Replace a pretrained classifier head and use model-specific normalization.

### Theory and reasoning

CNNs learn hierarchical spatial features; pretrained backbones can reduce data needs but may not match target domain. Macro F1 weights classes equally; confusion matrix identifies specific class confusions. Latency depends on hardware, batch and preprocessing.

### Worked scenario

Fine-tune a small pretrained model on an image dataset or use a synthetic offline baseline.

### Design and verification

Using pretrained model with wrong channel order or normalization silently hurts accuracy; follow model card and verify sample inputs.

### Practice

Compare a scratch CNN and pretrained backbone using the same split.

Acceptance: Report macro F1, per-class confusion and inference time.
