# LAB04 — XOR and nonlinear networks

**Lesson:** D01-L02

## Goal
Fit linear and nonlinear classifiers to the four XOR points.

## Setup
Use the core environment; additional packages: torch. Run commands from archive root.

## Steps
1. Read `content/D/D01/D01-L02.md` and the task below.
2. Run `python labs/starters/LAB04.py`. The TODO is intentional. Implement the missing contract in the starter; keep the provided fixtures and assertions where available.
3. Record both accuracies and explain representational limits.
4. Run the completed starter and inspect output. Add one independent boundary or failure case before submitting.
5. Compare to `labs/solutions/LAB04.py` after submission; run `python labs/solutions/LAB04.py` to reproduce the reference.

## Acceptance criteria
MLP fits all four points; linear model cannot. This is not a generalization benchmark.

## Submission
Source, test log, output/metrics, and a short limitation statement.

## Extension
Change a seed, input or boundary condition, then explain the result. Do not tune on the held-out test.
