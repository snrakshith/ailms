# Suggested learning roadmap

36 weeks, flexible and self-paced. Lesson estimates include reading and practice; capstone hours are additional.

| ----- | --------------------------------- | ----------------------------------------------------- | ---------------------: |
| 1–3   | Foundations                       | F01, F02                                              |                   16.2 |
| 4–10  | Machine Learning                  | M01, M02, M03, M04, M05                               |                   32.8 |
| 11–16 | Deep Learning                     | D01, D02, D03, D04                                    |                   27.8 |
| 17–21 | Computer Vision                   | C01, C02, C03, C04                                    |                   22.0 |
| 22–33 | Generative AI & Agent Engineering | G01, G02, G03, G04, G05, G06, G07, G08, G09, G10, G11 |                   79.8 |
| 34–36 | Production AI Engineering         | P01, P02                                              |                   12.5 |

## Progression gates

- Foundations: clean notebook run; explain matrices, gradient descent and Bayes rule.
- ML: leakage-safe baseline and holdout report.
- DL: implement train/eval loop and verify gradients.
- CV: correct image geometry and metric calculations.
- GenAI: demonstrate bounded, grounded agent with evaluation.
- Production: quality-gated release and rollback plan.

Suggested gate: at least 75% on rubric-scored exercises and knowledge checks; address critical privacy, leakage or security failures before proceeding.
