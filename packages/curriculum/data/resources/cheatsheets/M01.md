# ML lifecycle and data preparation — quick reference

## ML problem framing and baselines
**Recall:** To quantify whether additional modeling complexity improves outcomes.

**Watch for:** Choosing an algorithm before defining the target or using information unavailable at prediction time.

**Verify:** Prediction horizon, input availability, split and cost of errors are explicit.

## Train, validation, test and leakage
**Recall:** No, fit them on training data only.

**Watch for:** Feature leakage from future data, repeated entities or target-derived columns.

**Verify:** No user overlap where required; test timestamps follow train timestamps for forecasting.

## Preprocessing and feature pipelines
**Recall:** Each fold must learn preprocessing only from its training partition.

**Watch for:** Unknown categories at inference or fitting preprocessing using the whole dataset.

**Verify:** Prediction succeeds with the same feature schema; fit uses training only.
