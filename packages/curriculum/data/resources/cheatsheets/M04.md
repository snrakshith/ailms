# Unsupervised learning — quick reference

## Clustering: k-means, hierarchical and DBSCAN
**Recall:** They are not density-reachable under the selected parameters.

**Watch for:** Treating clusters as true labels or relying on a single internal score.

**Verify:** Explain which geometries and parameter choices fit the data.

## Dimensionality reduction: PCA, t-SNE and UMAP
**Recall:** No; global geometry can be distorted.

**Watch for:** Interpreting all distances and cluster sizes in t-SNE as meaningful.

**Verify:** Document seed, settings and visualization limitations.

## Anomaly detection and novelty detection
**Recall:** Scoring new observations against a model of normal training data.

**Watch for:** Training on future incidents or assuming every anomaly is malicious.

**Verify:** Report false positives and sensitivity to changing baseline behavior.
