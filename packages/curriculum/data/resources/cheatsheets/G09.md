# LLM APIs, gateways and guardrails — quick reference

## FastAPI, Pydantic and async inference APIs
**Recall:** No; it mainly helps overlap waiting for I/O.

**Watch for:** Blocking an async event loop, returning secrets in exceptions or accepting unbounded requests.

**Verify:** Tests cover success, invalid input, timeout and error responses.

## Streaming responses: SSE, chunks and cancellation
**Recall:** It helps clients distinguish a finished response from an interrupted connection.

**Watch for:** Assuming each chunk is valid JSON or leaking unsafe content before moderation completes.

**Verify:** Events are framed correctly; cancellation stops unnecessary work.

## LiteLLM gateway, routing and fallback
**Recall:** Centralize access, routing, quotas, cost tracking and cross-provider integration.

**Watch for:** Retrying non-idempotent side effects or switching models that do not support the required schema.

**Verify:** Log selected model, failure reason, latency and cost metadata without secrets.

## Guardrails, prompt injection, privacy and HITL
**Recall:** The model can be manipulated or mistaken; runtime authorization is authoritative.

**Watch for:** Relying solely on an LLM judge or releasing unreviewed streamed content.

**Verify:** Fail closed for protected actions; escalation and audit events are recorded.
