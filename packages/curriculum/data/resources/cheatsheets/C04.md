# Advanced vision and multimodal perception — quick reference

## Video, optical flow and object tracking
**Recall:** A tracker assigns a different identity to an object previously tracked under another identity.

**Watch for:** Ignoring frame-rate variation, occlusion or identity switches.

**Verify:** Document track creation/deletion and failure cases.

## Vision transformers, CLIP and multimodal vision
**Recall:** It scores image embeddings against text embeddings for candidate classes.

**Watch for:** Assuming zero-shot scores are calibrated or ignoring training-data bias.

**Verify:** Report macro F1 and prompt sensitivity on a fixed split.

## OCR, document AI, 3D and deployment
**Recall:** Detected regions must map correctly back to the source image.

**Watch for:** Logging sensitive documents or ignoring coordinate transforms during resizing.

**Verify:** Return structured outputs, verify preprocessing parity and measure failures.
