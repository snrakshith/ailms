# Supervised learning algorithms — quick reference

## Linear and polynomial regression

**Recall:** Observed target minus predicted target.

**Watch for:** High-degree polynomials can overfit; correlation is not causal effect.

**Verify:** Select the model by validation performance, not lowest training error.

## Logistic regression and classification thresholds

**Recall:** Class decisions and confusion-matrix metrics, not the fitted probability model.

**Watch for:** Treating probabilities as calibrated without checking or optimizing accuracy for rare positives.

**Verify:** Decision threshold is justified by validation costs, not by test outcomes.

## k-nearest neighbors, naive Bayes and SVM

**Recall:** Distance-based kNN and many SVM configurations.

**Watch for:** Unscaled features dominate distances; kernel SVM can be expensive on large data.

**Verify:** Preprocessing is inside folds and trade-offs are documented.

## Decision trees and random forests

**Recall:** It averages diverse estimators whose errors are not perfectly correlated.

**Watch for:** Unconstrained trees memorize training data; impurity importance can favor high-cardinality features.

**Verify:** Report the generalization gap and a stable configuration.

## Gradient boosting: XGBoost, LightGBM and CatBoost

**Recall:** Bagging aggregates independently trained models; boosting fits learners sequentially to improve the current ensemble.

**Watch for:** Using early stopping on test data or encoding categories inconsistently.

**Verify:** Log validation metric, runtime and chosen iteration count.

## Regularization, feature selection and bias-variance

**Recall:** No; excessive regularization can cause underfitting.

**Watch for:** Selecting features using all targets before cross-validation leaks information.

**Verify:** Identify high bias or high variance and propose one intervention.
