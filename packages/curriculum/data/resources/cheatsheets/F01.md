# Python and developer tooling — quick reference

## Python environments and notebooks

**Recall:** To detect hidden execution-order dependencies and missing setup.

**Watch for:** Installing into the wrong interpreter or relying on stale notebook variables.

**Verify:** The notebook runs top-to-bottom without manual state; the interpreter matches the environment.

## Python data types, control flow and functions

**Recall:** No; explicit validation or a library is needed.

**Watch for:** Mutable default arguments can retain state across calls.

**Verify:** Empty input returns an empty dictionary; repeated calls are independent.

## NumPy arrays, broadcasting and vectorization

**Recall:** Equal dimensions or a dimension of size one, aligned from the right.

**Watch for:** Dividing by zero or silently broadcasting along the wrong axis.

**Verify:** Nonconstant columns have near-zero mean and unit variance; the constant column remains finite.

## Pandas, data cleaning and EDA

**Recall:** To prevent accidental row multiplication or lost records.

**Watch for:** Many-to-many joins can unexpectedly multiply rows; test-set exploration can bias model selection.

**Verify:** Report row counts before and after joins and identify nonunique keys.

## Git, testing and reproducible experiments

**Recall:** Code version, data version, dependency versions, parameters and metrics.

**Watch for:** Committing credentials or assuming seeds alone guarantee reproducibility.

**Verify:** Tests pass independently; secrets are not in the repository.
