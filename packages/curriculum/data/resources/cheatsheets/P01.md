# MLOps and delivery engineering — quick reference

## Model packaging, APIs and Docker
**Recall:** To avoid train-serving skew.

**Watch for:** Loading untrusted pickle/joblib artifacts or training on service startup.

**Verify:** Container runs without training or secrets baked into image.

## MLflow, data versioning and experiment tracking
**Recall:** A run records an experiment; a version identifies a registered model artifact.

**Watch for:** Storing sensitive data in experiment metadata or promoting based on training score.

**Verify:** Runs include code/data identifiers and reproducible configuration.

## CI/CD, continuous training and DevSecOps
**Recall:** Correct software can still serve a degraded or unsafe model.

**Watch for:** Automatically promoting a retrained model without comparing it to a baseline.

**Verify:** Failed tests or quality gates block release; artifacts are immutable.
