# Deep learning training engineering — quick reference

## Datasets, DataLoaders and training loops
**Recall:** They control module behavior and gradient recording separately.

**Watch for:** Forgetting eval mode changes dropout and batch normalization behavior.

**Verify:** Training changes weights; evaluation does not; batch sizes are handled correctly.

## Normalization, dropout and early stopping
**Recall:** Random activation masks are sampled during training.

**Watch for:** Evaluating with dropout active or selecting checkpoints using test loss.

**Verify:** Restore the best validation checkpoint and report test once.

## Mixed precision, GPUs and distributed training
**Recall:** Replicas process different data batches and synchronize gradients.

**Watch for:** Assuming lower precision is always faster or forgetting effective batch size changes.

**Verify:** Report precision, device, batch size, throughput and numerical anomalies.
