# Image classification and datasets — quick reference

## Image datasets, augmentation and labeling
**Recall:** Neighboring frames can be near duplicates, inflating validation performance.

**Watch for:** Applying random training augmentations to validation or flipping labels with directional meaning.

**Verify:** Validation transforms are deterministic and label geometry remains consistent.

## Image classification and pretrained CNNs
**Recall:** Prevents its parameters from updating while the head learns.

**Watch for:** Forgetting pretrained input normalization or evaluating only overall accuracy.

**Verify:** Report macro F1, per-class confusion and inference time.
