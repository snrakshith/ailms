# Neural architectures and transformers — quick reference

## CNN foundations and receptive fields

**Recall:** It reduces parameters and applies the same local feature detector across positions.

**Watch for:** Confusing channels-first and channels-last layout or shrinking spatial dimensions unexpectedly.

**Verify:** Computed shapes match actual tensor shapes.

## RNNs, LSTMs, GRUs and sequence modeling

**Recall:** How information is retained, updated and exposed in hidden state.

**Watch for:** Shuffling tokens within a sequence or treating padding as real observations.

**Verify:** Evaluate on sequences not used in training and explain failure cases.

## Attention and transformers

**Recall:** To moderate score magnitude as key dimension grows.

**Watch for:** Mask polarity errors and quadratic attention memory for long sequences.

**Verify:** Changing future tokens does not alter earlier outputs.

## Encoder, decoder and encoder-decoder architectures

**Recall:** Decoder-only transformers, though other architectures exist.

**Watch for:** Assuming every transformer has identical masking or can generate text autoregressively.

**Verify:** Each diagram correctly indicates access to future input and target tokens.
