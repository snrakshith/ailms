# Neural network fundamentals — quick reference

## Tensors, autograd and PyTorch fundamentals
**Recall:** PyTorch accumulates gradients rather than replacing them automatically.

**Watch for:** In-place mutation of tracked tensors or mixing CPU and GPU tensors.

**Verify:** Gradient equals 2*x within tolerance.

## Perceptrons, MLPs and activation functions
**Recall:** Without them, stacked linear layers cannot represent nonlinear decision boundaries.

**Watch for:** Applying sigmoid to logits before BCEWithLogitsLoss or using incompatible target shape.

**Verify:** MLP can fit XOR; linear baseline cannot perfectly separate it.

## Forward pass, backpropagation and loss functions

**Watch for:** Detaching a tensor breaks its gradient path; incorrect logits/target shapes can silently mislead.

**Verify:** Analytic and autograd gradients agree.

## Optimizers, initialization and learning-rate schedules
**Recall:** Weight decay from the adaptive gradient update.

**Watch for:** Confusing L2 regularization with decoupled weight decay for adaptive optimizers.

**Verify:** Choose based on validation and stability rather than a single training curve.
