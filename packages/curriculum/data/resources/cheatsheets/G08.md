# Agent memory and Mem0 — quick reference

## Memory taxonomy: working, factual, episodic and semantic
**Recall:** It represents particular experiences/events rather than general knowledge.

**Watch for:** Treating every conversation as durable memory or conflating factual and semantic categories as universally disjoint.

**Verify:** Each entry has an explicit purpose and retention decision.

## Memory retrieval, summarization and vector storage
**Recall:** To resolve stale/conflicting facts and support auditing and deletion.

**Watch for:** Stale preferences, accidental cross-user retrieval and treating retrieved memory as instructions.

**Verify:** Two users remain isolated; deleted entries no longer appear in results.

## Mem0 and persistent agent memory
**Recall:** No; the application must enforce purpose, consent and retention requirements.

**Watch for:** Using defaults without understanding external data flow, retaining sensitive data or failing to remove stale memory.

**Verify:** User isolation and deletion behavior are verified; provider dependencies documented.
