# Classical computer vision — quick reference

## Image representation, color spaces and OpenCV
**Recall:** BGR for default color images.

**Watch for:** Displaying BGR as RGB or overflowing uint8 during arithmetic.

**Verify:** Shapes and dtype are recorded; channel conversion is correct.

## Filtering, edges and morphology
**Recall:** Erosion followed by dilation using a structuring element.

**Watch for:** Over-smoothing removes important detail; morphology depends on kernel and polarity.

**Verify:** Preserve target shape while removing isolated noise.

## Geometric transforms, calibration and features
**Recall:** Fits a model robustly by testing candidate subsets and selecting strong inlier support.

**Watch for:** Homographies fail for many nonplanar scenes; feature matches can contain outliers.

**Verify:** Use robust estimation and report geometric assumptions.
