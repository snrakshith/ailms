# Applied ML and experimentation — quick reference

## Time series, forecasting and backtesting
**Recall:** It simulates repeated forecasts using only historical information.

**Watch for:** Random splitting or calculating rolling features that include future observations.

**Verify:** All prediction dates follow their training data; forecast horizon is constant.

## Recommendation and learning to rank
**Recall:** It reduces the number of items requiring expensive ranking.

**Watch for:** Random negative sampling can misrepresent unseen relevance and cold-start performance.

**Verify:** Report recall@k for warm and cold-start segments separately.

## Causal inference and experimentation
**Recall:** No; causal claims need a valid identification strategy.

**Watch for:** Conditioning on post-treatment variables or repeatedly peeking at p-values without adjustment.

**Verify:** Plan addresses interference, missing data and statistical uncertainty.
