# Detection and segmentation — quick reference

## Object detection: boxes, IoU, NMS and mAP

**Recall:** Intersection area divided by union area.

**Watch for:** Mixing xyxy and xywh coordinates or comparing mAP computed under different IoU settings.

**Verify:** Unit tests cover no overlap, exact match and different classes.

## YOLO, Faster R-CNN, DETR and detection training

**Recall:** It learns set prediction with matching and commonly avoids conventional NMS.

**Watch for:** Comparing published speed numbers from different hardware or resolution.

**Verify:** Record architecture, data license, image size, IoU settings and hardware.

## Semantic, instance and panoptic segmentation

**Recall:** Instance segmentation separates individual objects of the same class.

**Watch for:** Including ignored pixels in metrics or using bilinear interpolation for discrete labels.

**Verify:** Tests include empty masks and documented empty-class conventions.

## U-Net, Mask R-CNN, SAM and foundation vision models

**Recall:** They recover spatial detail from earlier encoder features.

**Watch for:** Assuming promptable models are accurate for every domain or using unlicensed imagery.

**Verify:** Report per-case IoU and prompts; note domain limitations.
