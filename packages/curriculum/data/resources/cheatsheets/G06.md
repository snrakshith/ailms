# LangChain and LangGraph orchestration — quick reference

## LangChain components and integration boundaries

**Recall:** It isolates provider/framework changes from domain logic and tests.

**Watch for:** Tightly coupling business logic to provider-specific responses or using deprecated examples uncritically.

**Verify:** Tests run without network; provider failures return controlled errors.

## LangGraph state, nodes, edges and sequential workflow

**Recall:** When required stages and their order are known in advance.

**Watch for:** Mutating shared state unexpectedly or placing unrelated data in the graph.

**Verify:** Each node has a clear state contract and can be unit-tested.

## LangGraph conditional and parallel workflows

**Recall:** They define how concurrent updates combine rather than overwrite or conflict.

**Watch for:** Multiple branches updating the same state key without merge semantics.

**Verify:** Both branches contribute exactly once; invalid routes terminate.

## LangGraph iterative workflows, checkpointing and HITL

**Recall:** Replayed steps must not repeat harmful external effects.

**Watch for:** Re-executing a side effect on resume or storing secrets in checkpoint state.

**Verify:** No write occurs before approval; duplicate resume does not duplicate side effects.
