# Advanced RAG patterns — quick reference

## Self-reflective RAG and Self-RAG
**Recall:** It incorporates learned reflection tokens in the trained model.

**Watch for:** Calling any retry loop the original Self-RAG algorithm or trusting a self-grader without validation.

**Verify:** Stop on max attempts and preserve evidence for every decision.

## Corrective RAG (CRAG)
**Recall:** Poor or uncertain retrieved evidence before generation.

**Watch for:** Sending sensitive queries to unapproved search or using corrective results without provenance.

**Verify:** Route tests cover strong, weak, ambiguous and unavailable fallback cases.

## Self-corrective RAG and iterative verification
**Recall:** It targets the generated claims rather than only the retrieved documents.

**Watch for:** Infinite loops and a judge repeatedly approving its own hallucination.

**Verify:** All runs terminate; unsupported claims are removed or flagged.

## Agentic RAG and routing
**Recall:** When one predictable retrieval path handles the task reliably.

**Watch for:** Unbounded tool calls, cross-tenant retrieval or unnecessary agency for simple questions.

**Verify:** Report route accuracy, recall, tool count and cost proxy.
