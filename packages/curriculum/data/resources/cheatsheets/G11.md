# LLM adaptation and multimodal AI — quick reference

## Fine-tuning datasets, SFT and PEFT/LoRA

**Recall:** Learn a low-rank weight update while keeping the base weights frozen.

**Watch for:** Training on benchmark answers, poor data formatting or assuming fine-tuning adds reliable current facts.

**Verify:** Report trainable parameters, data provenance and validation metrics.

## QLoRA, quantization, serving and model optimization

**Recall:** Attention key/value states for previously processed tokens to avoid recomputation.

**Watch for:** Assuming four-bit storage equals complete runtime memory or every GPU supports every kernel.

**Verify:** Document hardware, model, quality, throughput and actual peak memory.

## Multimodal LLMs, diffusion apps and fine-tuning decisions

**Recall:** When facts must be retrieved and updated independently with traceable evidence.

**Watch for:** Treating fine-tuning as a replacement for retrieval or submitting private images to unapproved providers.

**Verify:** Justify modality, evidence source, model choice, and privacy controls.
