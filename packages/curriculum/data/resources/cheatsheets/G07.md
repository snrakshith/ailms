# MCP and FastMCP — quick reference

## Model Context Protocol (MCP) fundamentals

**Recall:** Interfaces for AI applications to discover and access external capabilities and context.

**Watch for:** Equating MCP with an agent framework or trusting every discovered capability.

**Verify:** Explain the difference between tool execution and resource access.

## FastMCP server and client development

**Recall:** They communicate the input contract and enable validation.

**Watch for:** Exposing filesystem or shell tools without restrictions, or assuming SDK and standalone FastMCP APIs are interchangeable.

**Verify:** Discovery works and validation rejects malformed arguments.

## MCP security, remote deployment and interoperability

**Recall:** No; server identity, authorization and runtime enforcement establish trust boundaries.

**Watch for:** Token passthrough without audience validation, prompt injection and SSRF through arbitrary URLs.

**Verify:** Unauthorized data is denied and logs omit secrets.
