# Evaluation and reliable model selection — quick reference

## Classification, regression and ranking metrics
**Recall:** A majority-class predictor can score highly while missing nearly all positives.

**Watch for:** AUC does not identify an operating threshold and accuracy can hide minority failures.

**Verify:** Metric choice matches business costs and includes subgroup analysis.

## Cross-validation and hyperparameter search
**Recall:** Estimating generalization of a model-selection procedure without using outer folds for tuning.

**Watch for:** Repeatedly tuning against the final test set invalidates it.

**Verify:** Split strategy and search budget are recorded.

## Imbalanced learning, calibration and uncertainty
**Recall:** Among comparable predictions near 0.8, roughly 80% should be positive.

**Watch for:** Oversampling before splitting leaks duplicate or related rows; calibration requires separate data or folds.

**Verify:** Report threshold, prevalence and calibration approach.

## Interpretability, fairness and error analysis
**Recall:** No, model attribution is not causal identification.

**Watch for:** Treating feature attribution as causality or reporting only aggregate accuracy.

**Verify:** Small groups are flagged; proposed mitigations are evaluated on validation data.
