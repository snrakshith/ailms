# RAG foundations — quick reference

## Embeddings, similarity and vector databases

**Recall:** No; it stores and indexes vectors generated elsewhere.

**Watch for:** Mixing embedding models in one index or missing tenant filters.

**Verify:** Record model, dimension, metric and metadata filter behavior.

## RAG ingestion, chunking and indexing

**Recall:** To enforce access and provide verifiable citations and lifecycle control.

**Watch for:** Indexing private content without access metadata or dropping document boundaries.

**Verify:** Chunks trace to source spans and old versions can be removed.

## RAG retrieval, reranking and answer grounding

**Recall:** Improve relevance ordering among retrieved candidates.

**Watch for:** Using similarity as proof of factual support or citing sources not actually retrieved.

**Verify:** Answer cites only available source IDs and abstains on unanswerable queries.

## RAG evaluation and retrieval diagnostics

**Recall:** Yes; it may be correct from prior knowledge without support from retrieved evidence.

**Watch for:** Evaluating only final answer similarity can hide retrieval failure or unsupported claims.

**Verify:** Show per-query evidence and abstention behavior, not just averages.
