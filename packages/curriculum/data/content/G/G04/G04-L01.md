# Self-reflective RAG and Self-RAG

**G04-L01 · Advanced · 135 min including practice**

## Learning objective
Compare model-trained reflection signals with application-level grading loops.

## Concept notes
Self-RAG is a research method using learned reflection tokens to control retrieval and critique generations. Application-level self-reflective RAG may instead use separate graders for evidence relevance, grounding and answer usefulness; these are related but not identical.

## Worked scenario
Retrieve evidence, grade relevance, generate and run a grounding check before returning an answer.

## Common mistake
Calling any retry loop the original Self-RAG algorithm or trusting a self-grader without validation.

## Deeper theory and design

Self-RAG research trains a model to retrieve and emit reflection tokens; a generic self-reflective RAG application instead adds an external grader and retry loop. They are related but not identical. Reflection only improves quality if feedback is informative and independently checked.

## Debugging clinic

Letting a model approve its own unsupported answer can reinforce hallucination. Use gold examples and external evidence checks; measure false-accept rate.
