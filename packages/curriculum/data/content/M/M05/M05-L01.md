# Time series, forecasting and backtesting

**M05-L01 · Intermediate · 105 min including practice**

## Learning objective
Use time-aware validation, lag features and forecasting baselines.

## Concept notes
Forecasting predicts future values with temporal dependence, seasonality and trends. Rolling-origin backtests preserve order; features must be available at forecast creation. Seasonal naive and exponential smoothing provide useful baselines.

## Worked scenario
Forecast weekly demand using last week's value and lagged features.

## Common mistake
Random splitting or calculating rolling features that include future observations.

## Practice exercise
Build three expanding-window backtests and compare MAE to seasonal naive.

**Acceptance criteria:** All prediction dates follow their training data; forecast horizon is constant.

## Deeper theory and design

A forecasting evaluation must mimic information available at forecast origin. Expanding windows increase training history while rolling windows forget old regimes. Seasonal naive uses the last corresponding seasonal value; horizon and aggregation matter.

## Debugging clinic

Random split permits future leakage; use ordered windows and avoid centered rolling features.
