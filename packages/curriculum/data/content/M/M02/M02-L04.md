# Decision trees and random forests

**M02-L04 · Intermediate · 105 min including practice**

## Learning objective
Explain recursive splitting, impurity and bagging.

## Concept notes
A tree greedily partitions feature space using impurity or loss reduction. A random forest aggregates trees trained on resampled data and random feature subsets, reducing variance compared with many individual trees.

## Worked scenario
Train a shallow tree and random forest on a nonlinear classification task.

## Common mistake
Unconstrained trees memorize training data; impurity importance can favor high-cardinality features.

## Deeper theory and design

Trees recursively split to reduce impurity; unconstrained depth can memorize noise. Random forests aggregate decorrelated trees trained on bootstrap samples and random feature subsets, reducing variance. More trees reduce Monte Carlo variability but cost memory and inference.

## Debugging clinic

Training accuracy reaches 1.0 but validation declines; reduce depth, min_samples_leaf or use a forest and verify on unseen data.
