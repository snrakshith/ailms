# M04-L01 — Clustering: k-means, hierarchical and DBSCAN: worked solution

## Problem

Compare silhouette scores and visual structure across algorithms.

## Worked approach

Generate blobs and moons; scale features. Run KMeans(n_clusters=2), AgglomerativeClustering and DBSCAN with several eps values. Plot labels and compute silhouette when at least two nontrivial clusters exist; treat noise separately and report coverage. Compare geometry, not just score.

## Failure analysis

Treating DBSCAN noise as an ordinary cluster distorts silhouette. Report noise rate and explain score calculation.

## Acceptance check

Explain which geometries and parameter choices fit the data.
