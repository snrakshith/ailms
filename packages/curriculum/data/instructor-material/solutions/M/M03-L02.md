# M03-L02 — Cross-validation and hyperparameter search: worked solution

## Problem

Run randomized search and report mean, standard deviation and final holdout performance once.

## Worked approach

Split a final test, then RandomizedSearchCV over a pipeline with n_iter=10, stratified 5-fold CV, fixed seed and scoring. Record candidate means/stds, selected params, refit on development data, score test once. For groups pass groups to group-aware CV.

## Failure analysis

Search iterations increase after seeing test performance. Retire that test as selection data and obtain a fresh holdout.

## Acceptance check

Split strategy and search budget are recorded.

## Submission evidence

Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
