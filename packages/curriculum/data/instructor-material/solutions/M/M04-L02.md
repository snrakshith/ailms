# M04-L02 — Dimensionality reduction: PCA, t-SNE and UMAP: worked solution

## Problem

Compare PCA explained variance and multiple nonlinear embeddings.

## Worked approach

Scale digits features; fit PCA and report cumulative explained variance for first components. Run t-SNE with two seeds and perplexities below sample size; optionally UMAP with fixed seed. Compare nearest-neighbor preservation and plots, and record parameters.

## Failure analysis

Interpreting distances between t-SNE islands as real distances is unjustified; check original-space neighbors and repeat seeds.

## Acceptance check

Document seed, settings and visualization limitations.
