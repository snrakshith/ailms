# M02-L04 — Decision trees and random forests: worked solution

## Problem
Compare train and validation scores across tree depths and forest sizes.

## Worked approach
Compare max_depth [2,5,None] for DecisionTreeClassifier and RandomForestClassifier with n_estimators [20,100], same split and seed. Record train/validation accuracy, gap and runtime. Prefer stable validation performance; optionally use repeated folds.

## Failure analysis
Training accuracy reaches 1.0 but validation declines; reduce depth, min_samples_leaf or use a forest and verify on unseen data.

## Acceptance check
Report the generalization gap and a stable configuration.

## Submission evidence
Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
