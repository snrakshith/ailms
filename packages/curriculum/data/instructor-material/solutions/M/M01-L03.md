# M01-L03 — Preprocessing and feature pipelines: worked solution

## Problem

Build a pipeline and predict a row with a missing number and unseen category.

## Worked approach

Create numeric SimpleImputer(strategy='median') plus StandardScaler; categorical SimpleImputer(strategy='most_frequent') plus OneHotEncoder(handle_unknown='ignore'). Combine via ColumnTransformer, then LogisticRegression. Fit a training DataFrame with numeric and category columns; predict a row with NaN and unseen 'new'. Check output shape and input schema.

## Failure analysis

Fitting the encoder before split leaks category information; put it inside the pipeline passed to cross-validation.

## Acceptance check

Prediction succeeds with the same feature schema; fit uses training only.
