# M02-L03 — k-nearest neighbors, naive Bayes and SVM: worked solution

## Problem

## Worked approach

Use the same stratified five folds for scaled KNeighborsClassifier, GaussianNB and scaled SVC. Use cross_validate with scoring='balanced_accuracy', return_train_score=True. Record mean, spread, fit_time and inference constraints. Keep each estimator's preprocessing within its pipeline.
