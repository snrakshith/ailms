# M05-L02 — Recommendation and learning to rank: worked solution

## Problem

Compare popularity baseline with nearest-neighbor recommendations.

## Worked approach

Construct implicit interaction table with user,item,time. Hold each eligible user's latest interaction out. Compute popularity from train, compare nearest-neighbor/co-occurrence scores excluding seen items. Recall@k = relevant retrieved / relevant held out, separately for warm and cold items; record unsupported cases.

## Failure analysis

Including held-out interactions in similarity matrix leaks targets. Rebuild every feature from training interactions.

## Acceptance check

Report recall@k for warm and cold-start segments separately.
