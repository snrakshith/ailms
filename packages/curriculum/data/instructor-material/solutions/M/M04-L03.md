# M04-L03 — Anomaly detection and novelty detection: worked solution

## Problem
Evaluate precision at a fixed daily alert budget using labeled anomalies.

## Worked approach
Fit IsolationForest on reference data, compute anomaly scores on labeled future data, rank most anomalous, select top daily K. Calculate precision@K and recall, repeat under a shifted baseline. Record legitimate seasonal shifts as false alarms.

## Failure analysis
Training on contaminated data or reversing score sign hides real anomalies. Inspect score direction and review labeled examples.

## Acceptance check
Report false positives and sensitivity to changing baseline behavior.
