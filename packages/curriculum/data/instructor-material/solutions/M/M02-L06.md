# M02-L06 — Regularization, feature selection and bias-variance: worked solution

## Problem
Plot learning curves and validation error for several penalty strengths.

## Worked approach
Use pipeline StandardScaler and Ridge with alpha [.001,.1,10,100]. Plot mean train and validation error over sample fractions via learning_curve, choose alpha using validation. High errors on both suggest bias; low train/high validation suggests variance. Repeat folds to avoid overinterpreting noise.

## Failure analysis
Feature selection performed using all labels leaks information; put SelectKBest inside pipeline and rerun cross-validation.

## Acceptance check
Identify high bias or high variance and propose one intervention.
