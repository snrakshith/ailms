# M05-L03 — Causal inference and experimentation: worked solution

## Problem
Specify unit of randomization, primary outcome, guardrail metrics and analysis plan.

## Worked approach
For recommendation experiment randomize by user, measure 14-day conversion per assigned user (intention to treat), guardrails latency and complaints. Set minimum detectable effect, compute sample-size plan, define missing-event handling and fixed stopping rule. Check balance and spillover risks.

## Failure analysis
Randomizing sessions when users see both experiences contaminates effects. Randomize by stable user or cluster, document interference.

## Acceptance check
Plan addresses interference, missing data and statistical uncertainty.

## Submission evidence
Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
