# M02-L02 — Logistic regression and classification thresholds: worked solution

## Problem

Plot precision and recall for several thresholds and pick one for a review capacity.

## Worked approach

Fit a pipeline on train; obtain validation probabilities. For thresholds .2,.4,.6,.8 compute precision, recall and count selected. If reviewers can handle K cases, sort by score and select top K or choose a threshold that satisfies capacity. Freeze selection then evaluate holdout.

## Failure analysis

Using .5 regardless of imbalance/cost may exceed budget or miss positives. Calibrate scores and pick threshold on validation, not test.

## Acceptance check

Decision threshold is justified by validation costs, not by test outcomes.
