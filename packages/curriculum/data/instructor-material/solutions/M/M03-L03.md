# M03-L03 — Imbalanced learning, calibration and uncertainty: worked solution

## Problem

Compare precision-recall, Brier score and calibration curves on a natural-prevalence holdout.

## Worked approach

Fit imbalanced classifier with class_weight as an option. On natural-prevalence validation compare average precision, Brier score and reliability bins with counts; use CalibratedClassifierCV on development folds if needed. Select operating threshold on separate validation and evaluate natural-prevalence test.

## Failure analysis

Oversampling before split duplicates positives into holdout; resample inside training only and do not change test prevalence.

Report threshold, prevalence and calibration approach.
