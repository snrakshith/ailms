# D03-L01 — CNN foundations and receptive fields: worked solution

## Problem
Design a CNN and calculate the shape after each layer before running it.

## Worked approach
Input N×3×32×32, Conv2d(3,8,3,padding=1) yields N×8×32×32; MaxPool2d(2) yields 16×16; second conv 8→16 kernel3 stride2 padding1 gives 8×8. Run torch layers, assert each shape, flatten 16*8*8 before linear head.

## Failure analysis
Flatten size mismatch occurs when stride/padding changes. Print intermediate shapes or infer feature dimension with a dummy pass.

## Acceptance check
Computed shapes match actual tensor shapes.
