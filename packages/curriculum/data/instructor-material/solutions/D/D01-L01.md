# D01-L01 — Tensors, autograd and PyTorch fundamentals: worked solution

## Problem
Compute an analytic gradient and compare with autograd.

## Worked approach
Use `x=torch.tensor([1.,2.,3.],requires_grad=True); loss=(x*x).sum(); loss.backward()`. Expect grad [2,4,6]. Compare `torch.allclose(x.grad,2*x.detach())`. Clear x.grad before another backward pass and rebuild the graph.

## Failure analysis
Calling `.detach()` or converting to NumPy before loss disconnects the gradient; inspect requires_grad and grad_fn.

## Acceptance check
Gradient equals 2*x within tolerance.
