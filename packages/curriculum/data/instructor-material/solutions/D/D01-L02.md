# D01-L02 — Perceptrons, MLPs and activation functions: worked solution

## Problem

Compare a linear model with an MLP on XOR.

## Worked approach

Use four XOR points and binary targets, train Linear(2,1) vs Sequential(Linear(2,8),Tanh(),Linear(8,1)) using BCEWithLogitsLoss and a fixed seed. Evaluate sigmoid > .5 on all four; MLP can reach 4/4, linear cannot. Try multiple seeds and log convergence.

## Failure analysis

Applying sigmoid before BCEWithLogitsLoss applies sigmoid twice. Feed raw logits and threshold only for evaluation.

## Acceptance check

MLP can fit XOR; linear baseline cannot perfectly separate it.
