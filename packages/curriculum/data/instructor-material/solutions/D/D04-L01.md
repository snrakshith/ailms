# D04-L01 — Transfer learning, embeddings and self-supervised learning: worked solution

## Problem

Compare frozen and partially unfrozen models on a small validation set.

## Worked approach

Choose small dataset, split first. Fit classifier on frozen backbone embeddings; then unfreeze last block with smaller lr, train same budget. Count sum(p.numel() for p in model.parameters() if p.requires_grad); compare validation metric and test once after selection. Record model revision.

## Failure analysis

Frozen parameters do not guarantee batch-norm running stats stay fixed; set frozen modules to eval if required.

## Acceptance check

Log trainable parameters, data split and performance.
