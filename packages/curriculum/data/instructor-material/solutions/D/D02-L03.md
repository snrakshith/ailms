# D02-L03 — Mixed precision, GPUs and distributed training: worked solution

## Problem
Compare throughput and validation loss on available hardware; if CPU-only, calculate memory estimates.

## Worked approach
On CPU estimate 10M fp32 parameters as 40 MB weights, another 40 MB gradients, roughly 80 MB Adam moments, excluding activations. If compatible GPU exists, compare autocast vs fp32 at same batch and synchronized timing, check finite gradients and validation loss. Report actual peak memory and hardware.

## Failure analysis
Comparing asynchronous GPU timings without synchronization misreports throughput; warm up and synchronize around measurements.

## Acceptance check
Report precision, device, batch size, throughput and numerical anomalies.

## Submission evidence
Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
