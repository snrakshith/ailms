# D01-L04 — Optimizers, initialization and learning-rate schedules: worked solution

## Problem
Train short runs at several learning rates and log loss curves.

## Worked approach
Use one fixed train/validation split and clone initial weights for runs at lr=[.001,.01,.1]. Train same epochs, log train/validation loss and nonfinite gradients. Choose best stable validation score; optionally try warmup or decay. Reset optimizer state for each run.

## Failure analysis
Reusing optimizer moments across trials invalidates comparison; initialize weights and optimizer consistently.

## Acceptance check
Choose based on validation and stability rather than a single training curve.
