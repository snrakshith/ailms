# D03-L03 — Attention and transformers: worked solution

## Problem
Implement small causal attention with a triangular mask and test future-token invariance.

## Worked approach
Use torch random Q,K,V (1,4,8), scores=Q@K.transpose(-2,-1)/sqrt(8), mask upper triangle above diagonal, softmax then @V. Change final token K,V and confirm first three outputs unchanged. Also test all valid rows have sum 1.

## Failure analysis
Applying mask after softmax leaves incorrect normalization; mask scores before softmax, avoid fully masked rows or define safe handling.

## Acceptance check
Changing future tokens does not alter earlier outputs.
