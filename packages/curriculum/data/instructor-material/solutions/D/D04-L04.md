# D04-L04 — Reinforcement learning and preference optimization: worked solution

## Problem
Implement a two-armed bandit and report cumulative regret across seeds.

## Worked approach
Simulate Bernoulli arms p=.3,.7 over 1000 trials; epsilon-greedy selects random arm with probability .1 else largest empirical mean; update counts and means. Compare epsilon=0,.1,.5 across seeds, regret sum(.7−p[action]). Report means/spread. Relate only conceptually to LLM preferences.

## Failure analysis
Evaluating one seed can reward lucky initialization; average across seeds and distinguish observed reward from expected regret.
