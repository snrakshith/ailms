# D02-L02 — Normalization, dropout and early stopping: worked solution

## Problem
Compare baseline, dropout and weight decay using validation curves.

## Worked approach
Train baseline, dropout and weight-decay variants using same data/seed. Each epoch track validation loss, deep-copy best state_dict, stop after e.g. five non-improving epochs. Restore best state, switch eval and evaluate test once. Compare gaps and runtime.

## Failure analysis
Saving `best=model.state_dict()` without copying may retain references to changing tensors; deepcopy or serialize checkpoint immediately.

## Acceptance check
Restore the best validation checkpoint and report test once.
