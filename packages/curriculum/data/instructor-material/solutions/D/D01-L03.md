# D01-L03 — Forward pass, backpropagation and loss functions: worked solution

## Problem

Hand-derive gradients for a scalar linear prediction and squared loss.

## Worked approach

Let w=2,b=1,x=3,y=4: ŷ=7, loss=9, gradients 18 and 6. Create scalar torch weights with requires_grad, compute loss, backward and compare. For batched mean loss divide summed per-example gradients by n.

## Failure analysis
