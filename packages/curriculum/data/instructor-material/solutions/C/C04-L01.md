# C04-L01 — Video, optical flow and object tracking: worked solution

## Problem
Create a synthetic video sequence with crossing objects and compare identity errors.

## Worked approach
Generate frames with a moving square; compute centroid displacement and optional Farneback flow, then associate detections by nearest predicted center with distance gate. Test occlusion and reappearance; count ID switches and missed tracks. Real videos require annotated identities for quantitative evaluation.

## Failure analysis
Nearest-neighbor association swaps IDs at crossings; add motion prediction/appearance and evaluate on crossing cases.

## Acceptance check
Document track creation/deletion and failure cases.
