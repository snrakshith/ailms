# C01-L02 — Filtering, edges and morphology: worked solution

## Problem
Compare masks for multiple kernel sizes and quantify foreground area.

## Worked approach
Construct 64×64 binary mask with 20×20 square and isolated pixels. Apply cv2.morphologyEx with 3×3 and 7×7 kernels, compare foreground counts and IoU with clean square. Pick smallest kernel removing noise without damaging shape.

## Failure analysis
Large erosion removes thin defects; evaluate object retention and noise reduction against annotated examples.

## Acceptance check
Preserve target shape while removing isolated noise.
