# C02-L02 — Image classification and pretrained CNNs: worked solution

## Problem

Compare a scratch CNN and pretrained backbone using the same split.

## Worked approach

Use fixed train/val/test image split. Train small CNN and pretrained backbone head with documented normalization; if weights unavailable, mark pretrained run pending. Report validation macro F1, class confusion, warmed batch-1 latency and parameter count; choose candidate before test.

## Failure analysis

Using pretrained model with wrong channel order or normalization silently hurts accuracy; follow model card and verify sample inputs.

## Acceptance check

Report macro F1, per-class confusion and inference time.

## Submission evidence

Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
