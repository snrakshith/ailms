# C03-L02 — YOLO, Faster R-CNN, DETR and detection training: worked solution

## Problem
Train or fine-tune a detector on a small custom dataset; profile latency and mAP.

## Worked approach
Create small labeled dataset with train/validation split by scene. Convert boxes to detector format and visualize conversions. Fine-tune available model using documented recipe, evaluate AP at stated IoU, latency and failure slices (small/occluded objects). If weights unavailable, deliver dataset audit and test format only.

## Failure analysis
Mixing normalized center-width-height with pixel corners corrupts training. Round-trip transform annotations and plot on image.

## Acceptance check
Record architecture, data license, image size, IoU settings and hardware.

## Submission evidence
Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
