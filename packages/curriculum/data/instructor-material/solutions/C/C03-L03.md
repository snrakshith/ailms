# C03-L03 — Semantic, instance and panoptic segmentation: worked solution

## Problem

Implement mask metrics and evaluate per-class scores on synthetic masks.

## Worked approach

Use truth mask with 4 positives, predicted with 3, overlap 2: union=5, IoU=.4, Dice=4/7. Build binary and multiclass examples, report per-class metrics and macro average; choose empty-empty as ignored or 1 and document. Draw two touching objects to illustrate instance vs semantic.

## Failure analysis

Pixel accuracy can be high on mostly background images; report class-specific overlap and object-level failure cases.

## Acceptance check

Tests include empty masks and documented empty-class conventions.

## Submission evidence

Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.

## Grading rubric (10 points)

- Correct mechanism or design: 4
- Evidence against acceptance criteria: 3
- Failure handling and boundary cases: 2
- Reproducibility and limitations: 1
