# C01-L01 — Image representation, color spaces and OpenCV: worked solution

## Problem

Create a synthetic color image, convert spaces and verify channel values.

## Worked approach

Create uint8 array (8,8,3), set BGR pixel [0,0,255] red; cv2.cvtColor(...,COLOR_BGR2RGB) yields [255,0,0]. Convert HSV and inspect hue near 0 with high saturation/value. Assert shape/dtype and label channel order.

## Failure analysis

Displaying BGR as RGB swaps red and blue. Convert at library boundaries and document normalization ranges.

## Acceptance check

Shapes and dtype are recorded; channel conversion is correct.
