# C01-L03 — Geometric transforms, calibration and features: worked solution

## Problem
Apply a perspective transform and quantify inlier matches or reprojection error.

## Worked approach
Define four source corners and destination quadrilateral; getPerspectiveTransform then perspectiveTransform and calculate mean pixel error on four known correspondences. Add more noisy correspondences and use findHomography(...,RANSAC); report inlier count and error on held-out points if available.

## Failure analysis
A homography fitted to four points exactly may be wrong for nonplanar scenes; inspect additional correspondences and camera geometry.

## Acceptance check
Use robust estimation and report geometric assumptions.
