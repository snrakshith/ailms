# C04-L02 — Vision transformers, CLIP and multimodal vision: worked solution

## Problem

Evaluate two prompt templates and inspect misclassified images.

## Worked approach

Compare two candidate text templates per class on fixed images using a compatible pretrained CLIP model; normalize embeddings, compute cosine similarity, choose highest score. Record prompts, revision, class set, per-class results; if unavailable, use toy normalized vectors only as mechanics demo.

## Failure analysis

Choosing prompts after seeing test labels overfits benchmark. Tune on development images and freeze templates.

## Acceptance check

Report macro F1 and prompt sensitivity on a fixed split.

## Submission evidence

Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
