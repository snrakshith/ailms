# C03-L04 — U-Net, Mask R-CNN, SAM and foundation vision models: worked solution

## Problem
Evaluate segmentation quality for difficult cases such as occlusion or small objects.

## Worked approach
Use small image/mask set, train U-Net baseline if compute available, compare with prompted masks from an available SAM checkpoint and instance masks from Mask R-CNN when labels support them. Fix prompt policy, evaluate IoU/Dice, latency and missed small objects. Record revision/weights or pending.

## Failure analysis
Comparing SAM with ground-truth box prompts to fully automatic U-Net is not equivalent; disclose prompt information and report separate tracks.

## Acceptance check
Report per-case IoU and prompts; note domain limitations.

## Submission evidence
Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.

- Correct mechanism or design: 4
- Evidence against acceptance criteria: 3
- Failure handling and boundary cases: 2
- Reproducibility and limitations: 1
