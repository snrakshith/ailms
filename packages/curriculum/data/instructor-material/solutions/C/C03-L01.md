# C03-L01 — Object detection: boxes, IoU, NMS and mAP: worked solution

## Problem
Implement IoU and class-aware NMS for a few predicted boxes.

## Worked approach
For boxes [0,0,2,2] and [1,1,3,3], intersection=1, union=7, IoU=1/7. Implement max/min overlap with zero guards, sort descending score and suppress same-class boxes with IoU>threshold. Test identical, disjoint and different-class boxes.

## Failure analysis
Class-agnostic NMS removes overlapping different objects. Use class-aware suppression unless task explicitly needs otherwise.

## Acceptance check
Unit tests cover no overlap, exact match and different classes.
