# C02-L01 — Image datasets, augmentation and labeling: worked solution

## Problem
Create a dataset audit with class counts, duplicates, split groups and annotation examples.

## Worked approach
Build manifest image_id,class,source_group,split. Count by class, hash exact duplicates, group split by camera/object, inspect annotations visually. For training flips update x coordinates (x_min'=W−x_max for half-open boxes); validation resize/normalize deterministically. Assert no group overlap.

## Failure analysis
Applying random augmentation to validation changes reported metric across runs; use deterministic transforms and preserve labels.

## Acceptance check
Validation transforms are deterministic and label geometry remains consistent.

## Submission evidence
Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
