# C04-L03 — OCR, document AI, 3D and deployment: worked solution

## Problem
Build an OCR or image inference mini-pipeline with latency and error tests.

## Worked approach
Choose sample document with known transcription; record recognized lines and boxes, compute character error rate via edit distance/reference length. For model export test identical input through original and ONNX runtime with tolerance and timing. For 3D, document camera intrinsics/depth units; unavailable integrations stay pending.

## Failure analysis
Comparing normalized vs original-size boxes breaks source citations; retain page coordinates and transformation metadata.

## Acceptance check
Return structured outputs, verify preprocessing parity and measure failures.

## Submission evidence
Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.

## Grading rubric (10 points)
- Correct mechanism or design: 4
- Evidence against acceptance criteria: 3
- Failure handling and boundary cases: 2
- Reproducibility and limitations: 1
