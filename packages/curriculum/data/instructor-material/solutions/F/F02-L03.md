# F02-L03 — Probability, distributions and Bayes rule: worked solution

## Problem

Use prevalence 1%, sensitivity 90% and specificity 95% to calculate posterior.

## Worked approach

Among 10,000 cases expect 100 positives of which 90 test positive; 9,900 negatives yield 495 false positives. Posterior 90/(90+495)=0.153846. Verify with a probability expression and repeat for 10% prevalence to see the base-rate effect.

## Failure analysis

Confusing sensitivity with positive predictive value gives 90%. Draw a frequency table and compute the denominator across both classes.

## Acceptance check

Posterior is about 15.4%, not 90%.
