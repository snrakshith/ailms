# F02-L05 — Calculus, gradients and optimization: worked solution

## Problem
Compare trajectories for learning rates 0.1, 0.9 and 1.1.

## Worked approach
Start x=3, iterate 12 times at η=.1,.9,1.1 and record x². Multipliers .8, −.8, −1.2 respectively: first converges monotonically in x, second changes sign while loss decreases, third grows. Plot loss on a log scale; handle zero carefully.

## Failure analysis
Looking only at loss hides sign oscillation. Plot parameters and loss together and check gradient magnitude.

## Acceptance check
Identify convergence, oscillation and divergence using loss values.
