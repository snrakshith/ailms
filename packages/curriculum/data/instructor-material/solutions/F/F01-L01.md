# F01-L01 — Python environments and notebooks: worked solution

## Problem

Create an environment, run a notebook from a fresh kernel and record Python/package versions.

## Worked approach

Run `uv venv --python 3.11`, then `uv pip install --python .venv/bin/python numpy ipykernel` (Windows: `.venv\Scripts\python.exe`). Register the kernel with `python -m ipykernel install --user --name ai-lab` using the environment interpreter. In the first cell print `sys.executable` and `np.__version__`; restart and run all cells. Record the package versions with `uv pip freeze` targeting the same environment.

## Failure analysis

A notebook succeeds only after running cell 9 first. Move definitions before use, restart, then run all; check executable rather than blindly reinstalling.

## Acceptance check

The notebook runs top-to-bottom without manual state; the interpreter matches the environment.
