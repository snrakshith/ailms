# F01-L02 — Python data types, control flow and functions: worked solution

## Problem
Implement a count-by-category function handling empty input and missing labels.

## Worked approach
Define `def count(rows):` and create `out = {}` inside it. For each row use `key = row.get('label') or 'unknown'`, then `out[key] = out.get(key, 0) + 1`. Return out. For `[{'label':'a'}, {}, {'label':'a'}]` expect `{'a':2,'unknown':1}`; empty input returns `{}`. If numeric or empty labels are legitimate, use an explicit None check instead.

## Failure analysis
A default argument `out={}` accumulates previous calls. Move initialization into the function; call twice and verify independent results.

## Acceptance check
Empty input returns an empty dictionary; repeated calls are independent.
