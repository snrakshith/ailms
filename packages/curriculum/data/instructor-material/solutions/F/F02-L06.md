# F02-L06 — Information theory and numerical stability: worked solution

## Problem
Compute negative log likelihood for both probabilities and explain the penalty.

## Worked approach
For p=.9 and .1, loss ≈.10536 and 2.30259. Use `-np.log(np.clip(p,1e-12,1))` as a teaching approximation; for logits use framework cross-entropy directly. Verify softmax([1000,1001]) after subtracting max is approximately [.269,.731].

## Failure analysis
Exponentiating large logits returns inf; avoid probabilities rounded to zero and use logits-based losses where possible.

## Acceptance check
The 0.1 prediction has the higher loss; use stable log handling.
