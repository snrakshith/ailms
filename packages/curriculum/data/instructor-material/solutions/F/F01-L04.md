# F01-L04 — Pandas, data cleaning and EDA: worked solution

## Problem
Create a data-quality report with missing counts, duplicate keys and label distribution.

## Worked approach
Create a table with ids [1,2,2], labels [0,1,1] and one missing numeric value. Use `df.isna().sum()`, `df.duplicated('id',keep=False)`, `df.label.value_counts(dropna=False,normalize=True)`. Inspect key counts on both tables; use `merge(...,validate='many_to_one')` when the right side is unique. Log before/after rows and investigate any unexpected multiplication.

## Failure analysis
A many-to-many merge doubles positive cases and inflates apparent performance. Assert expected cardinality and audit duplicated keys before training.

## Acceptance check
Report row counts before and after joins and identify nonunique keys.
