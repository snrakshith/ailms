# F02-L01 — Linear algebra: vectors, matrices and dot products: worked solution

## Problem

Compute batch scores by hand for two rows and verify with NumPy.

## Worked approach

For X=[[1,2],[3,4]], w=[2,-1], b=0.5, compute row scores 0.5 and 2.5 by hand. Verify `np.array(X) @ np.array(w)+.5`, assert shape (2,) and values. Interpret positive weights as increasing score conditional on other features.

## Failure analysis

Elementwise X*w returns a matrix, not scores. Sum along feature axis or use @, and check dimensions.

## Acceptance check

Scores match and output shape is (2,).
