# F01-L05 — Git, testing and reproducible experiments: worked solution

## Problem

Write three tests for a numerical feature transformer and document a run command.

## Worked approach

Implement `scale(x,lo,hi)` with an explicit error for hi<=lo. Assert endpoints map to 0 and 1, midpoint maps to .5, invalid range raises ValueError. Run `python -m unittest` or pytest; record interpreter, seed, data hash and Git commit. Add `.env` and generated artifacts to ignore rules; scan staged files.

## Failure analysis

A test passes alone but fails in the suite due to mutable global state. Create fixtures per test and remove shared mutation; rotate any credential accidentally committed.

## Acceptance check

Tests pass independently; secrets are not in the repository.

## Submission evidence

Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.

- Correct mechanism or design: 4
- Evidence against acceptance criteria: 3
- Failure handling and boundary cases: 2
- Reproducibility and limitations: 1
