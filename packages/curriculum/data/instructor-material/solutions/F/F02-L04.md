# F02-L04 — Statistics, sampling and confidence intervals: worked solution

## Problem

Generate bootstrap intervals for sample sizes 20 and 200 from the same distribution.

## Worked approach

Generate n=20 and n=200 standard normal samples with `default_rng(7)`. For each use 2000 resamples via `rng.choice(x,(2000,n),replace=True).mean(1)` and percentiles [2.5,97.5]. Report interval widths, repeat across seeds, and compare with theoretical standard error. Use block bootstrap for serial dependence.

## Failure analysis

Resampling individual time points breaks autocorrelation; use appropriate blocks or model-based intervals, and distinguish sample size from resample count.

## Acceptance check

Explain why larger samples generally yield narrower intervals.
