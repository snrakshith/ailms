# P01-L01 — Model packaging, APIs and Docker: worked solution

## Problem

Build a container and run a health check and prediction contract test.

## Worked approach

Package trained pipeline and version manifest, build minimal image with pinned dependencies and nonroot user, add health/readiness and prediction contract. Run with fixture input and invalid payload, inspect image history for secrets. Use trusted serialized artifacts only; sign and scan image before promotion. Container execution needs Docker runtime.

## Failure analysis

Loading untrusted pickle/joblib can execute code; restrict artifact origin and integrity verification.

## Acceptance check

Container runs without training or secrets baked into image.

## Submission evidence

Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
