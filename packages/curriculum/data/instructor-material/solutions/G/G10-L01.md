# G10-L01 — Agent evaluation, datasets and LLM-as-judge: worked solution

## Problem
Create a rubric with anchors, run pairwise comparisons in both orders and review disagreements.

## Worked approach
Create rubric 0 unsupported, 1 partially supported, 2 fully supported with cited facts and examples. Judge A/B and B/A in blind order, compare with human labels and count order flips/disagreements. Report model revision, prompt hash, temperature and per-slice agreement; adjudicate high-risk cases manually.

## Failure analysis
A judge rewards longer answer without checking evidence. Require claim-level anchors and independent human sample.

## Acceptance check
Report agreement, judge config and failure cases; do not use judge score alone.

## Submission evidence
Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.

## Grading rubric (10 points)
- Correct mechanism or design: 4
- Evidence against acceptance criteria: 3
- Failure handling and boundary cases: 2
- Reproducibility and limitations: 1
