# G07-L03 — MCP security, remote deployment and interoperability: worked solution

## Problem
Write a threat model and tests for cross-tenant requests and malformed resource IDs.

## Worked approach
Threat-model client credentials, remote server, tenant boundary, resource URIs and logs. Test invalid token, correct token wrong tenant, malformed path, oversized payload and hostile tool output. Enforce scoped checks server-side, rate limits, TLS and log redaction. Include discovery and capability-change approval.

## Failure analysis
Passing user-supplied tenant as authorization context permits cross-tenant access. Bind tenant to verified identity and query constraints.

## Acceptance check
Unauthorized data is denied and logs omit secrets.

## Submission evidence
Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.

## Grading rubric (10 points)
- Correct mechanism or design: 4
- Evidence against acceptance criteria: 3
- Failure handling and boundary cases: 2
- Reproducibility and limitations: 1
