# G03-L01 — Embeddings, similarity and vector databases: worked solution

## Problem

Implement brute-force cosine retrieval, then compare one vector backend.

## Worked approach

Use three vectors [1,0],[0,1],[1,1] with query [1,0]; normalized similarities 1,0,~.707. Rank using numpy; test zero vector handling. Compare vector backend top-k to exact search on same corpus with tenant filters; record recall, latency and index revision.

## Failure analysis

Mixing embeddings from different model revisions or returning results before applying tenant filter yields wrong or unauthorized evidence.

## Acceptance check

Record model, dimension, metric and metadata filter behavior.
