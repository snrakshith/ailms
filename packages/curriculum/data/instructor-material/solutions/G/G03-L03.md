# G03-L03 — RAG retrieval, reranking and answer grounding: worked solution

## Problem

Measure recall@k before/after hybrid retrieval and manually inspect citations.

## Worked approach

Create labeled queries with exact SKU and paraphrase cases; retrieve dense and lexical candidates, fuse with sum 1/(60+rank), optionally rerank. Compare recall@k and inspect evidence. Generate an answer using only allowed IDs, validate every citation against retrieval and manually check claim support.

## Failure analysis

A valid citation ID does not imply the cited text supports the claim. Evaluate entailment/faithfulness separately and show source snippets.

## Acceptance check

Answer cites only available source IDs and abstains on unanswerable queries.

## Submission evidence

Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
