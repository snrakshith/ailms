# G01-L02 — Tokens, tokenizers and context windows: worked solution

## Problem
Measure token counts for three strings and implement a context-budget check.

## Worked approach
Load AutoTokenizer for a reviewed local model revision, tokenize three texts including code and non-English text. Use apply_chat_template(...,tokenize=True,add_generation_prompt=True) to count complete input; reject if input_tokens+reserved_output>model_limit. Test exact-boundary and over-budget cases; drop lowest-priority chunks rather than silently losing system constraints.

## Failure analysis
Counting words underestimates chat overhead; measure rendered messages with actual tokenizer and check provider context limit separately.

## Acceptance check
Use the actual model tokenizer and reserve space for output.

Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
