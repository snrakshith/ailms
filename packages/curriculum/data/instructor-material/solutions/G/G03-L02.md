# G03-L02 — RAG ingestion, chunking and indexing: worked solution

## Problem
Build a chunker with stable IDs and test document update/deletion behavior.

## Worked approach
Split text into fixed windows (e.g. 100 words, overlap 20) with start/end offsets and sha256(doc_id,version,span,text). Index version 1, replace with version 2 transactionally, delete prior IDs and assert search excludes them. Preserve source location and access policy for each chunk.

## Failure analysis
Appending revised chunks without deleting stale records creates conflicting evidence. Implement version-aware upsert and tombstone/cleanup.

## Acceptance check
Chunks trace to source spans and old versions can be removed.

## Submission evidence
Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
