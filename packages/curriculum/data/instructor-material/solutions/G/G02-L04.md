# G02-L04 — Prompt serialization: ChatML, Alpaca and INST: worked solution

## Problem
Render two actual model templates and identify role and generation markers.

## Worked approach
Use two actual reviewed chat tokenizers with pinned revisions. Render a system/user/assistant sequence using apply_chat_template; inspect escaped text and IDs and add_generation_prompt behavior. If a role unsupported, handle according to card rather than invent markers. For conceptual comparison show `<&#124;im_start&#124;>user`, `### Instruction:` and `[INST]` as illustrative markers only.

## Failure analysis
Manually concatenating a generic INST prompt for an incompatible model yields malformed role boundaries. Use its provided chat template and test round trip.

## Acceptance check
Use the tokenizer's own template and document supported roles.
