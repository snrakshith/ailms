# G01-L03 — Decoding, sampling and inference constraints: worked solution

## Problem

Record five generations per setting and compare format compliance and diversity.

## Worked approach

Use one fixed prompt and model revision, generate five times at greedy and sampled configurations (e.g. temperature .7/top_p .9), log seeds if supported. Parse outputs with a schema and compare exact match, semantic correctness and diversity. Treat deterministic settings as separate from one-shot examples.

## Failure analysis

A consistently wrong answer looks reproducible; evaluate correctness and schema compliance, not just identical outputs.

## Acceptance check

Separate repeatability from factual accuracy.

## Submission evidence

Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
