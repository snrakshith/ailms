# G04-L01 — Self-reflective RAG and Self-RAG: worked solution

## Problem

Implement a bounded grade-and-retry loop with a deterministic mock grader and evaluate false accepts.

## Worked approach

Implement retrieve→generate→grade. Mock grader verifies cited IDs and expected fact, returns pass/fail. On failure rewrite query or retrieve alternate evidence, max 3 attempts then abstain. Test false accept (valid ID but unsupported statement), and log evidence, grade and stop reason on every step.

## Failure analysis

Letting a model approve its own unsupported answer can reinforce hallucination. Use gold examples and external evidence checks; measure false-accept rate.

## Acceptance check

Stop on max attempts and preserve evidence for every decision.

## Submission evidence

Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
