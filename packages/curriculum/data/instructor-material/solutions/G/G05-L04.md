# G05-L04 — Multi-agent systems and orchestration: worked solution

## Problem

Implement a supervisor with two mock specialists and bounded fan-out.

## Worked approach

Supervisor routes query to at most two specialists (policy and billing), each read-only and scoped. Gather result records containing claims/source IDs; merge by verified source priority, flag conflicts rather than voting. Test missing worker, contradictory results and budget exhaustion.

## Failure analysis

Giving each specialist every tool defeats least privilege. Restrict capabilities per worker and validate merged provenance.

## Acceptance check

Each worker has narrow tools; merge resolves conflicts and records provenance.

## Submission evidence

Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
