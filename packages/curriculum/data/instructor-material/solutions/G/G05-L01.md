# G05-L01 — Tool calling and tool-use agent pattern: worked solution

## Problem

Implement a tool registry, argument validation and unknown-tool error handling.

## Worked approach

Define registry `{'lookup': lookup}` with strict args and allowed scopes. Reject unknown tools, invalid ID and unauthorized user; invoke only after checks, return structured error or data. Add tests that denied calls leave invocation count unchanged. For writes require idempotency and explicit approval.

## Failure analysis

A valid JSON argument references another tenant's record. Enforce tenant from authenticated context, not caller-supplied fields.

## Acceptance check

Invalid and unauthorized calls do not execute; errors are structured.

## Submission evidence

Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
