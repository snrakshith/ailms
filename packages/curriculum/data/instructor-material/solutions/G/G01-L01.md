# G01-L01 — Generative AI landscape and LLM fundamentals: worked solution

## Problem

Classify five business use cases by generation, retrieval or deterministic computation.

## Worked approach

Compare three tasks: compute tax from explicit rates using normal code; classify ambiguous support messages using supervised or prompted model; answer policy questions with retrieval plus citations. For each define input, output contract, baseline, error cost and abstention path. Benchmark on held-out examples rather than assuming generative capability implies correctness.

## Failure analysis

Using a free-form model for arithmetic or authorization introduces avoidable errors; delegate deterministic decisions to verified functions.

## Acceptance check

Explain when a non-generative solution is preferable.

## Submission evidence

Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.

## Grading rubric (10 points)

- Correct mechanism or design: 4
- Evidence against acceptance criteria: 3
- Failure handling and boundary cases: 2
- Reproducibility and limitations: 1
