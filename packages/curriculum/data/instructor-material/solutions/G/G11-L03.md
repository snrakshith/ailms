# G11-L03 — Multimodal LLMs, diffusion apps and fine-tuning decisions: worked solution

## Problem
Design a benchmark and choose an architecture for document QA versus image generation.

## Worked approach
Design document QA benchmark with answer, page/region evidence and unanswerable cases; compare OCR+RAG vs compatible VLM. For image generation specify prompt adherence, artifact/safety review and latency. Choose modality based on evidence requirements, privacy and cost; evaluate baseline before fine-tuning.

## Failure analysis
Using an image generator for factual document extraction is mismatched; test OCR fidelity and citation geometry instead.

## Acceptance check
Justify modality, evidence source, model choice, and privacy controls.

## Submission evidence
Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.

## Grading rubric (10 points)
- Correct mechanism or design: 4
- Evidence against acceptance criteria: 3
- Failure handling and boundary cases: 2
- Reproducibility and limitations: 1
