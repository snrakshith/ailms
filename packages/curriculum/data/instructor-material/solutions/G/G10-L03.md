# G10-L03 — Ragas for RAG evaluation: worked solution

## Problem

Prepare a dataset with user input, retrieved contexts, response and reference; select appropriate metrics.

## Worked approach

Prepare records with user_input, retrieved_contexts, response, reference, gold source IDs. Choose metrics only after checking required columns in installed docs; compute deterministic source recall offline, run opt-in Ragas evaluation and report sample scores with judge/embedding versions. Analyze missing-context vs unsupported-answer failures.

## Failure analysis

Passing reference text as retrieved context artificially improves faithfulness; keep actual retrieval evidence separate from reference answer.

## Acceptance check

Report per-metric required columns, model and sample-level failure analysis.

## Submission evidence

Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
