# G04-L04 — Agentic RAG and routing: worked solution

## Problem

Compare deterministic routing with a bounded agent on a mixed question set.

## Worked approach

Create queries for FAQ, product docs, no retrieval and unknown. Baseline routes by explicit rules; adaptive mock chooses allowed tools based on observed evidence, max four actions. Compare route accuracy, evidence recall, tool counts and cost proxy; require abstention for unavailable facts.

## Failure analysis

Agent repeatedly searches irrelevant indices and misses SLA; impose route/tool budget, timeouts and explicit terminal conditions.

## Acceptance check

Report route accuracy, recall, tool count and cost proxy.

## Submission evidence

Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
