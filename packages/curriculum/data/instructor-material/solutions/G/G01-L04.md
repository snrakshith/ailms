# G01-L04 — Hugging Face Hub, Transformers and model selection: worked solution

## Problem
Compare three model cards for task fit, license, size and known limitations.

## Worked approach
Create table for three candidate models with exact repository, revision hash, license, context, size/precision, benchmark fit, safety limits and hardware. Verify each card and run a fixed task sample if weights are available. Decline unknown licenses or unreviewed remote code; record blocked models and justification.

## Failure analysis
Comparing advertised benchmarks across different datasets or prompts misleads. Run the same local evaluation and disclose revision and hardware.

## Acceptance check
Document exact revision and do not enable remote code without review.

## Submission evidence
Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.

## Grading rubric (10 points)
- Correct mechanism or design: 4
- Evidence against acceptance criteria: 3
- Failure handling and boundary cases: 2
- Reproducibility and limitations: 1
