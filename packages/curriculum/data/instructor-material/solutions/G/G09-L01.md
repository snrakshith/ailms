# G09-L01 — FastAPI, Pydantic and async inference APIs: worked solution

## Problem

Build a FastAPI service with health and validated inference endpoints.

## Worked approach

Define request text with length bounds and response label; POST /infer awaits mock adapter with asyncio.wait_for, maps timeout to 504 and known failure to 503. GET /health returns status. Use TestClient for valid request, malformed body 422, timeout and controlled error. No keys required for fake path.

## Failure analysis

Calling blocking inference directly inside async endpoint stalls event loop; move CPU work to appropriate executor or separate inference service.

## Acceptance check

Tests cover success, invalid input, timeout and error responses.

## Submission evidence

Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
