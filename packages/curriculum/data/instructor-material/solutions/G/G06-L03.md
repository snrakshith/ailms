# G06-L03 — LangGraph conditional and parallel workflows: worked solution

## Problem
Construct a mock router and two parallel branches with a deterministic reducer.

## Worked approach
Route 'both' to workers A/B (or a fan-out node), each returns result keyed by worker ID. Merge into sorted mapping, assert one record each. Route invalid input to terminal error. In actual LangGraph use documented conditional edges and Annotated reducer; test concurrency and duplicate keys.

## Failure analysis
Parallel nodes writing same key without reducer may error or overwrite. Define merge contract and test fan-in under reordered completion.

## Acceptance check
Both branches contribute exactly once; invalid routes terminate.

## Submission evidence
Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
