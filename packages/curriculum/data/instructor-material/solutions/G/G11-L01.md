# G11-L01 — Fine-tuning datasets, SFT and PEFT/LoRA: worked solution

## Problem

Create a small licensed instruction dataset, split it, configure LoRA and plan a baseline comparison.

## Worked approach

Create synthetic or properly licensed messages dataset, deduplicate and split by source. For d_in=d_out=4096,r=8 compute 65,536 vs 16,777,216 weights. Configure reviewed PEFT LoraConfig targeting model-specific modules; train only if compatible weights/compute, compare baseline and adapter on held-out quality/format/safety. Record actual trainable parameter count.

## Failure analysis

Using test examples in training or wrong chat format invalidates benchmark; inspect rendered examples and data provenance.

## Acceptance check

Report trainable parameters, data provenance and validation metrics.
