# G09-L02 — Streaming responses: SSE, chunks and cancellation: worked solution

## Problem

Implement SSE events for delta, done and error and test a canceled client.

## Worked approach

Async generator yields `event: delta\ndata: {json}\n\n` for chunks, then done; on controlled error emit error event, on CancelledError close upstream and re-raise. Test frame parsing, event order, mid-stream error and cancellation cleanup with fake generator; use StreamingResponse media_type='text/event-stream'.

## Failure analysis

A generator catches cancellation as generic error and keeps generating; ensure cleanup in finally and test canceled iteration.

## Acceptance check

Events are framed correctly; cancellation stops unnecessary work.
