# G10-L02 — DeepEval for LLM and agent regression tests: worked solution

## Problem

Write an offline exact-match test and a separate opt-in DeepEval semantic test.

## Worked approach

Write exact-match/schema assertions in unittest or pytest for fake model output. Add opt-in DeepEval test case with input, actual output, expected output/retrieval context as required by selected metric; log threshold and judge model. Gate optional test behind environment flag and compare failed examples manually.

## Failure analysis

Treating judge-dependent tests as offline makes CI flaky and costly. Separate jobs and mark skipped explicitly when no credentials.

## Acceptance check

Offline CI works without keys; judge-backed checks log thresholds and model.

## Submission evidence

Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
