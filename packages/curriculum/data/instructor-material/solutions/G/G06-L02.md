# G06-L02 — LangGraph state, nodes, edges and sequential workflow: worked solution

## Problem

Create a two-node offline graph and test the final state.

## Worked approach

Create TypedDict with `text`, `normalized`, `result`; node A strips/lowercases text, B computes length. Build StateGraph, add nodes, START→A→B→END, compile and invoke. Assert final normalized='hi' and result=2 for ' Hi '. Unit-test node functions directly; runtime integration requires installed LangGraph.

## Failure analysis

Mutating shared state in place obscures replay behavior. Return explicit updates and type-check state keys.

## Acceptance check

Each node has a clear state contract and can be unit-tested.

Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
