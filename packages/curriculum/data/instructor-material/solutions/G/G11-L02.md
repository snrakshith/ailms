# G11-L02 — QLoRA, quantization, serving and model optimization: worked solution

## Problem

Estimate weight and KV-cache memory and benchmark a compatible serving configuration if hardware is available.

## Worked approach

For 7B weights at 4 bits estimate 3.5 GB decimal raw weights; add quantization metadata, adapters and activations. KV estimate 2×layers×batch×sequence×KV_heads×head_dim×bytes. Benchmark compatible serving setup at fixed prompts, report p50/p95 latency, tokens/s, quality and peak memory, or mark hardware test pending.

## Failure analysis

Estimating only weights undercounts memory and can cause OOM at long contexts; include KV cache, workspaces and concurrency.

## Acceptance check

Document hardware, model, quality, throughput and actual peak memory.

## Submission evidence

Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
