# G06-L04 — LangGraph iterative workflows, checkpointing and HITL: worked solution

## Problem
Build a review gate and test approve, reject and resume cases.

## Worked approach
Create state with request_id, status='pending'; review node returns interrupt/approval request. Reject→terminal no write; approve→write with idempotency key request_id; resume duplicate→existing receipt. For actual LangGraph use a checkpointer, thread config and Command(resume=...) per installed version. Test all three outcomes.

## Failure analysis
Performing a write before interrupt can duplicate it after resume. Place side effects behind approval and transactional idempotency.

## Acceptance check
No write occurs before approval; duplicate resume does not duplicate side effects.
