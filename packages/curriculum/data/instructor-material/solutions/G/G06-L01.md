# G06-L01 — LangChain components and integration boundaries: worked solution

## Problem
Implement an adapter and swap a fake for one configured model.

## Worked approach
Define `ModelPort.generate(messages)->str` and FakeModel returning fixed text or raising TimeoutError. Wrap configured LangChain model in a separate adapter using its documented invoke API, map results into domain schema, set timeout/retry. Test fake success/failure offline and run real adapter only with explicit configuration.

## Failure analysis
Leaking provider exceptions or message classes into business logic makes migration and error handling brittle; normalize at boundary.

## Acceptance check
Tests run without network; provider failures return controlled errors.

## Submission evidence
Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
