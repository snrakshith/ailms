# G09-L04 — Guardrails, prompt injection, privacy and HITL: worked solution

## Problem
Threat-model an agent and build tests for injection, unauthorized actions and sensitive output.

## Worked approach
Define prohibited tool scopes and approval requirement for write. Test injected instructions in user/retrieved data, cross-tenant ID, unapproved write, output containing fixture secret and valid read. Assert deny/escalate states and no side effects; capture sanitized audit event. Test bypass attempts and false positives.

## Failure analysis
Using model decision as sole authorization creates bypass. Require authenticated policy checks and fail closed on unavailable policy service.

## Acceptance check
Fail closed for protected actions; escalation and audit events are recorded.

## Submission evidence
Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
