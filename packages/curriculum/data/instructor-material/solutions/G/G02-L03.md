# G02-L03 — Persona prompting, reasoning prompts and prompt injection: worked solution

## Problem
Compare persona vs neutral prompts and test input that asks to ignore instructions.

## Worked approach
Compare neutral and domain-persona prompts on same labeled questions, scoring accuracy and format. Add inputs containing instruction-like text, delimit data, enforce allowed actions outside model and test output. Require short answer justification or externally computed results; do not require private reasoning traces.

## Failure analysis
A persona says it may ignore access policy; enforce permission in application code, not a prompt claim.

## Acceptance check
Evaluate correctness and instruction adherence using external checks.

## Submission evidence
Include implementation or design artifact, test inputs and outputs, relevant dependency versions, and a short limitation statement. For external tools, report skipped integrations explicitly; a mock is not a live service test.
