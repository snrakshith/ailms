# DevSecOps incident and supply-chain evidence

Simulate a failed scanner, a malicious unsigned artifact (synthetic evidence), and a runtime alert. Show gates and response without attacking external systems.

## Deliverables
- Synthetic event log
- Gate result matrix
- Triage and exception record
- Postmortem

## 100-point rubric
- 35 points — Gate correctness
- 25 points — Response safety
- 25 points — Evidence and traceability
- 15 points — Communication

## Exit gate
Submit evidence and a written limitation; avoid unsupported claims of production readiness.
