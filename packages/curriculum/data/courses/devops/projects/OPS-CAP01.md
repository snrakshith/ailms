# Secure application delivery pipeline

Create an authorized local or disposable CI/CD + GitOps pipeline using starter app; record evidence for tests, scanning, signing, deployment, rollback and incident handling.

## Deliverables

- Threat model and architecture
- CI workflow with verified pins and least privilege
- Immutable artifact and SBOM/signature evidence
- Staging DAST and policy checks
- GitOps rollback and on-call runbook

## 100-point rubric

- 25 points — Build/test reproducibility
- 25 points — Security gates and failure handling
- 20 points — Deployment and rollback
- 15 points — Observability
- 15 points — Documentation and evidence

## Exit gate

Submit evidence and a written limitation; avoid unsupported claims of production readiness.
