# AWS infrastructure and platform golden path

Design an AWS two-AZ platform, using Terraform modules, least-privilege IAM and GitOps. Implement local Terraform plan and Kubernetes manifests; AWS apply is optional only with reviewed budget/permissions.

## Deliverables
- Network and IAM diagram
- Module contracts and plan
- Helm starter and onboarding SOP
- RTO/RPO and cost/cleanup plan

## 100-point rubric
- 25 points — Networking and access design
- 25 points — IaC and state safety
- 25 points — Reusable contract and deployment
- 15 points — Reliability
- 10 points — Documentation

## Exit gate
Submit evidence and a written limitation; avoid unsupported claims of production readiness.
