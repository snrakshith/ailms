# Learning roadmap

Suggested 24-week plan at roughly 4–6 hours/week plus capstone time; adapt to learner experience. Primary stack: GitHub Actions, Terraform, Docker, Kubernetes, Helm, Argo CD, Prometheus/Grafana; security: Semgrep, Gitleaks, Trivy, Checkov, ZAP. AWS is the cloud example; OpenTofu is mentioned as an alternative. Commercial/hosted integrations remain optional.

## Phase 1: DevOps foundations & delivery

Estimated 40.5 hours.

- Linux & shell
- Version control
- Continuous integration
- Container engineering
- Cloud & infrastructure as code
- Kubernetes
- Helm & GitOps
- Observability & SRE

## Phase 2: DevSecOps & supply chain

Estimated 32 hours.

- Security foundations
- Static application security
- Dependency and secrets security
- Artifact and infrastructure scanning
- Dynamic and policy security
- Runtime & software supply chain

## Phase 3: Production operations & platform engineering

Estimated 8 hours.

- Production operations

Complete the relevant capstone, revisit weak modules, and present your reasoning without notes.
