# DevOps & DevSecOps — Beginner to Advanced

LMS-ready study material, not a website.

**3 tracks, 15 modules, 47 lessons, 141 quiz items, 94 flashcards, 14 indexed labs, 3 capstones.**

Suggested 24-week plan at roughly 4–6 hours/week plus capstone time; adapt to learner experience. Primary stack: GitHub Actions, Terraform, Docker, Kubernetes, Helm, Argo CD, Prometheus/Grafana; security: Semgrep, Gitleaks, Trivy, Checkov, ZAP. AWS is the cloud example; OpenTofu is mentioned as an alternative. Commercial/hosted integrations remain optional.

Start with ROADMAP.md, SYLLABUS.md and SETUP.md. For LMS ingestion see LMS_IMPORT.md. Review VALIDATION.md before publication.

All practice examples are instructional. No independent review or production certification is claimed.
