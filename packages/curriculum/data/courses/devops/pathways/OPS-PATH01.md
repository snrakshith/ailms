# DevOps engineer

Linux, Git, CI/CD, containers, AWS/Terraform, Kubernetes, Helm, GitOps and observability. Study security fundamentals before real deployment.

## Suggested sequence
1. Linux & shell
2. Version control
3. Continuous integration
4. Container engineering
5. Cloud & infrastructure as code
6. Kubernetes
7. Helm & GitOps
8. Observability & SRE
9. Production operations

Prerequisite check: complete a diagnostic on skipped topics. Exit: demonstrate a portfolio project, explain trade-offs, and pass the module checks.
