# Algorithm interview toolkit

Build a tested pattern library and demonstrate one algorithm from each of 15 patterns. Use the source schedule to select independent practice, not memorize answers.

## Deliverables

- Code and tests
- Complexity table and invariants
- Mock interview notes
- Spaced repetition log

## 100-point rubric

- 40 points — Correctness and tests
- 25 points — Pattern selection and invariants
- 20 points — Complexity reasoning
- 15 points — Communication and retrospective

## Exit gate

Submit evidence and a written limitation; avoid unsupported claims of production readiness.
