# Setup

Python 3.10+ recommended (reference tests use standard library only). `python labs/tests/day_01.py` runs reference; `python labs/tests/day_01.py labs/starters/day_01.py` tests your completed starter. Run `python scripts/randomized_checks.py`. Optional notebook tools: `python -m pip install jupyterlab nbformat jsonschema` in a virtual environment; pin reviewed versions in your environment. Use `python scripts/validate.py` for metadata checks.

For Anki, import TSV with tab delimiter, Front/Back/Tags; skip header. Use a local editor or JupyterLab. No API keys are needed.
