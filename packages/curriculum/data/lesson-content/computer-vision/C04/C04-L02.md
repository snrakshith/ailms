# Vision transformers, CLIP and multimodal vision

**C04-L02 · Advanced · 135 min including practice**

## Learning objective

Explain patch embeddings, contrastive alignment and zero-shot vision.

## Concept notes

Vision Transformers tokenize image patches and use attention. CLIP-style models align image and text embeddings through contrastive learning; zero-shot classification compares image embeddings with textual class descriptions.

## Worked scenario

Compare class text prompts for a small image set and measure prompt sensitivity.

## Common mistake

Assuming zero-shot scores are calibrated or ignoring training-data bias.

## Practice exercise

Evaluate two prompt templates and inspect misclassified images.

**Acceptance criteria:** Report macro F1 and prompt sensitivity on a fixed split.

## Deeper theory and design

ViT splits images into patch tokens with positional information and transformer layers. CLIP-style contrastive learning aligns image/text embeddings; zero-shot classification depends on prompts and distribution. Similarity scores are not calibrated probabilities.

## Debugging clinic

Choosing prompts after seeing test labels overfits benchmark. Tune on development images and freeze templates.
