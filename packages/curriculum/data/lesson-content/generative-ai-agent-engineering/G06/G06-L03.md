# LangGraph conditional and parallel workflows

**G06-L03 · Intermediate · 105 min including practice**

## Learning objective

Route by state and merge independent branches safely.

## Concept notes

Conditional edges choose a destination using state; parallel branches execute independent work and need reducers or explicit merge contracts for concurrent state updates. Fan-out and fan-in should be bounded.

## Worked scenario

Route invalid inputs to rejection; run keyword and vector retrieval in parallel and merge IDs.

## Common mistake

Multiple branches updating the same state key without merge semantics.

## Practice exercise

Construct a mock router and two parallel branches with a deterministic reducer.

**Acceptance criteria:** Both branches contribute exactly once; invalid routes terminate.

## Deeper theory and design

Conditional edges choose routes from state; parallel branches may concurrently update state and require reducers for shared keys. Deterministic reducers should be associative where possible; ordering should be explicit rather than inferred from execution completion.

## Debugging clinic

Parallel nodes writing same key without reducer may error or overwrite. Define merge contract and test fan-in under reordered completion.
