# Guardrails, prompt injection, privacy and HITL

**G09-L04 · Advanced · 135 min including practice**

## Learning objective
Create layered safety controls and approval workflows.

## Concept notes
Input validation, output schema checks, tool authorization, PII handling, content policy checks and human review provide complementary defenses. Prompt injection treats untrusted content as attempted instructions; no single filter guarantees protection. Streaming may require buffering or incremental checks.

## Worked scenario
Block unauthorized writes even when a model claims approval and mask sensitive fields in logs.

## Common mistake
Relying solely on an LLM judge or releasing unreviewed streamed content.

## Practice exercise
Threat-model an agent and build tests for injection, unauthorized actions and sensitive output.

**Acceptance criteria:** Fail closed for protected actions; escalation and audit events are recorded.

## Deeper theory and design

Guardrails layer input validation, prompt-injection resistance, tool authorization, output checking and human review. No classifier or prompt alone eliminates attacks. Sensitive data policy and fail-closed protected actions must be enforced outside model generation.

## Debugging clinic

Using model decision as sole authorization creates bypass. Require authenticated policy checks and fail closed on unavailable policy service.
