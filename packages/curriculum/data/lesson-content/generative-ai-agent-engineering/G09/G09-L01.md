# FastAPI, Pydantic and async inference APIs

**G09-L01 · Intermediate · 105 min including practice**

## Learning objective
Expose validated inference endpoints with controlled errors.

## Concept notes
FastAPI maps HTTP requests to typed Python handlers; Pydantic defines data contracts. Async I/O helps concurrent network-bound calls; blocking CPU/GPU operations may require workers or separate inference services. Authentication, limits and timeouts belong at service boundaries.

## Worked scenario
Expose a typed prediction or chat endpoint and test malformed inputs.

## Common mistake
Blocking an async event loop, returning secrets in exceptions or accepting unbounded requests.

## Deeper theory and design

FastAPI maps HTTP requests to validated Pydantic models and response schemas. Async endpoints improve concurrency for awaited I/O, not CPU-bound inference by themselves. Timeouts, exception mapping, limits and health/readiness checks are separate concerns.

## Debugging clinic

Calling blocking inference directly inside async endpoint stalls event loop; move CPU work to appropriate executor or separate inference service.
