# Model Context Protocol (MCP) fundamentals

**G07-L01 · Intermediate · 105 min including practice**

## Learning objective

Explain host, client, server, tools, resources, prompts and transport.

## Concept notes

MCP standardizes how AI applications connect to external context and capabilities. A host coordinates clients; servers expose tools, resources and prompts. Transport and authorization depend on deployment and protocol revision. MCP does not grant permission automatically.

## Worked scenario

Design a server exposing read-only document search and a resource URI.

## Common mistake

Equating MCP with an agent framework or trusting every discovered capability.

## Practice exercise

Diagram host/client/server and define schemas and permissions for two capabilities.

**Acceptance criteria:** Explain the difference between tool execution and resource access.

## Deeper theory and design

MCP connects a host application to servers through clients; servers may expose tools, resources and prompts, with capabilities negotiated by protocol. Resources expose contextual data, tools execute operations, prompts offer reusable message templates; the host owns user consent and authorization policy.

## Debugging clinic

Treating all MCP servers as trusted extensions permits instruction injection or excessive access. Validate capabilities, inputs and server identity.
