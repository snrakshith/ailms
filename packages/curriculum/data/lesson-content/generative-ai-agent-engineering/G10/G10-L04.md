# Promptfoo for prompt/model evaluation and red teaming

**G10-L04 · Intermediate · 105 min including practice**

## Learning objective
Run test matrices across prompt/provider combinations and adversarial cases.

## Concept notes
Promptfoo supports declarative evaluation configurations, provider/prompt matrices and assertions. Some checks are deterministic; judge-based assertions use a configured model. Security testing needs permission, scoped targets and non-sensitive fixtures.

## Worked scenario
Evaluate two support prompts with regex/schema assertions and a rubric.

## Common mistake
Storing API keys in YAML or attacking systems without authorization.

## Practice exercise

## Deeper theory and design

Promptfoo evaluates prompt/model configurations against cases and assertions, including adversarial evaluations. Provider execution may cost money or send data externally. Deterministic checks and semantic checks have different failure modes.

## Debugging clinic

Only evaluating happy paths overlooks injection and format failures; keep adversarial holdouts and fail closed on protected action.
