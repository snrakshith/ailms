# Ragas for RAG evaluation

**G10-L03 · Intermediate · 105 min including practice**

## Learning objective
Measure retrieval and generation with appropriate reference data.

## Concept notes
Ragas offers metrics for retrieval and answer assessment, with metric-specific required fields and judge/embedding dependencies. Use human-reviewed examples to calibrate and distinguish context recall, precision and faithfulness.

## Worked scenario
Evaluate retrieval evidence against reference answers for a small question set.

## Common mistake
Using an unavailable reference field or comparing metrics across changed evaluator configurations.

## Practice exercise
Prepare a dataset with user input, retrieved contexts, response and reference; select appropriate metrics.

**Acceptance criteria:** Report per-metric required columns, model and sample-level failure analysis.

## Deeper theory and design

Ragas offers RAG-oriented metrics with required input fields that differ by metric and release. Faithfulness assesses support by retrieved contexts, while retrieval relevance/recall and answer correctness address other stages. Metric outputs depend on judge and embedding settings.

## Debugging clinic

Passing reference text as retrieved context artificially improves faithfulness; keep actual retrieval evidence separate from reference answer.
