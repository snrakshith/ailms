# Prompt serialization: ChatML, Alpaca and INST

**G02-L04 · Intermediate · 105 min including practice**

## Learning objective
Explain how messages become model-specific serialized token sequences.

## Concept notes
ChatML-style formats use role delimiters; Alpaca-style templates often use Instruction/Input/Response sections; [INST]-style formats mark instruction boundaries in certain model families. Exact control tokens and role rules vary by tokenizer and model revision.

## Worked scenario
Inspect tokenizer.apply_chat_template on system, user and assistant messages and compare conceptual templates.

## Common mistake
Manually applying the wrong template, duplicating special tokens or concatenating untrusted messages as instructions.

## Practice exercise
Render two actual model templates and identify role and generation markers.

**Acceptance criteria:** Use the tokenizer's own template and document supported roles.

## Deeper theory and design

ChatML, Alpaca and INST represent families of prompt serializations; exact markers, roles, EOS and generation suffixes vary across checkpoints. Training and inference formatting must align. Double-adding special tokens can degrade model behavior.

## Debugging clinic

Manually concatenating a generic INST prompt for an incompatible model yields malformed role boundaries. Use its provided chat template and test round trip.
