# Causal inference and experimentation

**M05-L03 · Advanced · 135 min including practice**

## Learning objective
Distinguish prediction, intervention and causal effects.

## Concept notes
Random assignment supports estimating treatment effects under assumptions; observational causal inference requires identification assumptions such as exchangeability and positivity. Confounders affect treatment and outcome. A/B tests need prespecified metrics and stopping rules.

## Worked scenario
Design an experiment comparing two recommendation interfaces.

## Common mistake
Conditioning on post-treatment variables or repeatedly peeking at p-values without adjustment.

## Practice exercise
Specify unit of randomization, primary outcome, guardrail metrics and analysis plan.

**Acceptance criteria:** Plan addresses interference, missing data and statistical uncertainty.

## Deeper theory and design

Random assignment helps identify treatment effects under assumptions including no interference. Define the estimand, primary outcome, guardrails, unit and analysis plan before seeing results. Confidence intervals represent uncertainty; repeated peeking changes error rates.

## Debugging clinic

Randomizing sessions when users see both experiences contaminates effects. Randomize by stable user or cluster, document interference.
