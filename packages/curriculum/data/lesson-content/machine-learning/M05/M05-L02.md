# Recommendation and learning to rank

**M05-L02 · Intermediate · 105 min including practice**

## Learning objective
Understand collaborative, content-based and ranking systems.

## Concept notes
Collaborative filtering learns from user-item interactions; content-based methods use item features. Two-stage systems retrieve candidates then rank them. Offline evaluation must avoid future interactions and account for exposure bias.

## Worked scenario
Recommend items by user-item similarity, then evaluate recall@k on held-out events.

## Common mistake
Random negative sampling can misrepresent unseen relevance and cold-start performance.

## Practice exercise
Compare popularity baseline with nearest-neighbor recommendations.

**Acceptance criteria:** Report recall@k for warm and cold-start segments separately.

## Deeper theory and design

Collaborative filtering learns from user-item interactions; content-based methods use item attributes. Offline ranking should exclude already seen items and split by time or user as appropriate. Cold-start requires metadata or popularity fallback.

## Debugging clinic

Including held-out interactions in similarity matrix leaks targets. Rebuild every feature from training interactions.
