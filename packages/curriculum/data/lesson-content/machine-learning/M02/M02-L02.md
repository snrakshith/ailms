# Logistic regression and classification thresholds

**M02-L02 · Beginner · 75 min including practice**

## Learning objective
Interpret logits, probabilities and decision thresholds.

## Concept notes
Logistic regression maps a linear score to a probability using the sigmoid for binary outcomes. Training often minimizes log loss; deployment chooses a decision threshold based on error costs.

## Worked scenario
Change a fraud threshold from 0.5 to 0.2 and observe recall and false alarms.

## Common mistake
Treating probabilities as calibrated without checking or optimizing accuracy for rare positives.

## Practice exercise
Plot precision and recall for several thresholds and pick one for a review capacity.

**Acceptance criteria:** Decision threshold is justified by validation costs, not by test outcomes.

## Deeper theory and design

Logistic regression maps a linear logit to sigmoid probability. Thresholding probabilities is a separate decision, controlled by cost and review capacity. Increasing threshold usually reduces false positives and recall, though precision need not be monotonic.

## Debugging clinic

Using .5 regardless of imbalance/cost may exceed budget or miss positives. Calibrate scores and pick threshold on validation, not test.
