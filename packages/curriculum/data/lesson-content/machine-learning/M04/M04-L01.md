## Learning objective

## Concept notes
k-means minimizes squared distance to centroids; hierarchical clustering builds nested groups; DBSCAN uses density connectivity and can mark noise. Scale and geometry strongly affect results.

## Worked scenario
Cluster synthetic crescent-shaped data using k-means and DBSCAN.

## Common mistake

## Deeper theory and design

k-means optimizes squared distance to centroids, assuming compact groups. Hierarchical clustering constructs a linkage tree; DBSCAN groups density-connected points and marks noise. Silhouette compares intra-cluster cohesion and nearest-cluster separation, but can favor convex groups.

## Debugging clinic

Treating DBSCAN noise as an ordinary cluster distorts silhouette. Report noise rate and explain score calculation.
