# Datasets, DataLoaders and training loops

**D02-L01 · Intermediate · 105 min including practice**

## Learning objective

Build explicit training and evaluation loops.

## Concept notes

Datasets define sample access; DataLoaders batch and optionally shuffle. A training loop runs forward, loss, backward and optimizer step. Evaluation uses model.eval() and disables gradient recording.

## Worked scenario

Train a classifier on generated features with batches and validation metrics.

## Common mistake

Forgetting eval mode changes dropout and batch normalization behavior.

## Practice exercise

Implement train_epoch and evaluate functions with sample-weighted losses.

**Acceptance criteria:** Training changes weights; evaluation does not; batch sizes are handled correctly.

## Deeper theory and design

Training toggles dropout and batch-norm behavior, computes gradients and updates parameters; evaluation should use model.eval and no_grad/inference_mode. Epoch average must weight batch means by batch size, especially when last batch is small.

## Debugging clinic

Averaging three batch means equally weights the final three examples too much; sum weighted losses and divide by count.
