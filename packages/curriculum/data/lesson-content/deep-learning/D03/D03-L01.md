# CNN foundations and receptive fields

**D03-L01 · Intermediate · 105 min including practice**

## Learning objective
Calculate convolution output shapes and explain weight sharing.

## Concept notes
Convolution slides kernels over spatial input with shared weights. Stride, padding and dilation control output dimensions and receptive field. Pooling summarizes neighborhoods and may reduce resolution.

## Worked scenario
Apply a 3x3 edge kernel and calculate output dimensions for stride 2.

## Common mistake
Confusing channels-first and channels-last layout or shrinking spatial dimensions unexpectedly.

## Practice exercise
Design a CNN and calculate the shape after each layer before running it.

**Acceptance criteria:** Computed shapes match actual tensor shapes.

## Deeper theory and design

Convolution output per dimension is floor((n+2p−d(k−1)−1)/s+1). Local receptive fields expand with depth and stride; shared weights reduce parameter count. Padding and pooling alter spatial resolution.

## Debugging clinic

Flatten size mismatch occurs when stride/padding changes. Print intermediate shapes or infer feature dimension with a dummy pass.
