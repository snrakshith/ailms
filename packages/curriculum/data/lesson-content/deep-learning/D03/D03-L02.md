# RNNs, LSTMs, GRUs and sequence modeling

**D03-L02 · Intermediate · 105 min including practice**

## Learning objective
Explain recurrence and gating for ordered data.

## Concept notes
RNNs update hidden state from current input and previous state. LSTM and GRU gates help control information flow and mitigate some long-range gradient issues. Padding and masks matter for variable-length sequences.

## Worked scenario
Predict the next symbol in a toy sequence with a GRU.

## Common mistake
Shuffling tokens within a sequence or treating padding as real observations.

## Practice exercise
Train a small GRU on synthetic sequences and compare to a naive baseline.

**Acceptance criteria:** Evaluate on sequences not used in training and explain failure cases.

## Deeper theory and design

RNN updates state sequentially; LSTM and GRU use gates to control information retention and mitigate vanishing gradients. Sequence batching requires consistent dimensions and masking padded positions. Temporal split is essential.

## Debugging clinic

Using padded last timestep instead of true sequence end corrupts representation; gather last valid state or pack sequences.
